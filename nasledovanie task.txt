Задача 1: Иерархия классов "Животные"
Создайте иерархию классов для моделирования различных животных. Вам нужно создать:

Базовый класс Animal, который содержит общие атрибуты:

Имя животного (name)
Возраст (age)
Метод для вывода информации о животном.
Класс Dog, наследующий от Animal:

Атрибут породы собаки (breed).
Переопределите метод вывода информации, добавив вывод породы.
Класс Cat, наследующий от Animal:

Атрибут цвета шерсти (furColor).
Переопределите метод для вывода цвета шерсти.
В главной функции создайте объекты Dog и Cat, заполните их данными и выведите информацию на экран.




Задача 2: Онлайн-магазин
Создайте иерархию классов для моделирования товаров в онлайн-магазине:

Базовый класс Product с атрибутами:

Название (name)
Цена (price).
Класс Electronics, наследующий от Product:

Мощность устройства (power).
Класс Clothing, наследующий от Product:

Размер одежды (size).
В главной функции создайте объекты товаров, заполните их данными и выведите информацию о каждом товаре.



Задача 3: Система оплаты труда
Создайте систему для расчета зарплат сотрудников:

Базовый класс Employee с атрибутами:

Имя (name)
Базовая зарплата (baseSalary).
Метод calculateSalary() для расчета зарплаты.
Класс HourlyEmployee, наследующий от Employee:

Количество отработанных часов (hoursWorked).
Оплата за час (hourlyRate).
Переопределите метод calculateSalary(), который вычисляет зарплату как hoursWorked * hourlyRate.
Класс SalariedEmployee, наследующий от Employee:

Фиксированная зарплата (fixedSalary).
Переопределите метод calculateSalary(), который возвращает фиксированную зарплату.
Класс Manager, наследующий от SalariedEmployee:

Процент бонуса (bonusPercentage).
Переопределите метод calculateSalary() для вычисления зарплаты с бонусом как fixedSalary + bonusPercentage * fixedSalary.
В главной функции создайте массив сотрудников, содержащий работников с почасовой оплатой, на фиксированной ставке и менеджеров. Выведите общую сумму зарплат.
