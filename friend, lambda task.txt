Задание 1: Создание системы счета баллов для студентов

Напишите программу, которая моделирует систему учета баллов для студентов с использованием класса Student. Каждый студент имеет имя и количество баллов за выполненные задания.

Создайте класс Student, который будет содержать приватные данные: имя студента и его баллы.

Реализуйте friend функцию, которая будет увеличивать баллы студента на определенное количество (например, за выполнение дополнительного задания).

Реализуйте лямбда-функцию внутри основной функции, которая будет проверять, получил ли студент достаточно баллов для сдачи экзамена (например, больше 50 баллов).

Используйте friend функцию для изменения состояния приватных переменных класса и лямбду для проверки условий.
Указания:
Класс Student должен содержать приватные члены для имени студента и его текущего количества баллов.
Friend функция должна принимать объект Student и увеличивать его баллы на заданное значение.
Лямбда-функция должна принимать объект Student и проверять, превышает ли его количество баллов заданный порог.
В функции main() создайте несколько объектов класса Student и проверьте их баллы после вызова friend функции и лямбда-функции.


Задание 2: Банк и счета
Создайте программу, которая моделирует работу банка, где каждый клиент имеет банковский счет. Программа должна:

Использовать класс BankAccount, который хранит информацию о счете клиента, включая баланс.

Реализовать friend функцию для перевода денег с одного счета на другой. Она должна иметь доступ к приватным полям классов и изменять баланс.

Реализовать лямбда-функцию, которая проверяет, является ли баланс счета отрицательным, и выводит предупреждение.

Указания:
Класс BankAccount должен содержать приватные данные для хранения имени клиента и его баланса.
Friend функция должна позволять переводить деньги с одного счета на другой.
Лямбда-функция должна проверять баланс каждого счета и выводить сообщение, если баланс стал отрицательным.
Реализуйте в функции main() создание нескольких счетов и выполнение операций перевода.
