Задача 1: Сумма чисел от 1 до N
Задача: Напишите программу, которая с помощью цикла for вычисляет сумму чисел от 1 до N, где N вводится пользователем.


Задача 2: Факториал числа
Задача: Напишите программу, которая с помощью цикла while вычисляет факториал числа N.


Задача 3: Проверка на простое число
Задача: Напишите программу, которая с помощью цикла do-while проверяет, является ли введенное число простым.

Задача 4: Обратный порядок чисел
Задача: Напишите программу, которая выводит числа от N до 1 в обратном порядке с использованием цикла for.

Задача 5: Сумма четных чисел от 1 до N
Задача: Напишите программу, которая вычисляет сумму всех четных чисел от 1 до N с использованием цикла while.

Задача 6: Таблица умножения
Задача: Напишите программу, которая выводит таблицу умножения для числа, введенного пользователем, с использованием цикла for.
