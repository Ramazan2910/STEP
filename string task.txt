
Task 1:

Пользователь вводит диапазон, а также значения и заполняет массив. Ваша задача если в массиве существует чётные элементы то их записать в новый масси, а предыдущий удалить если нет то вывести все числа.

Task 2: Подсчет количества слов в строке
Напишите программу, которая принимает строку и подсчитывает количество слов в ней. Словом считается последовательность символов, отделенная пробелами.



Task 3: Проверка палиндрома
Напишите программу, которая проверяет, является ли строка палиндромом (читается одинаково в обоих направлениях).



Task 4: Подсчет количества гласных и согласных
Программа принимает строку и выводит количество гласных и согласных букв.



Task 5: Удаление всех пробелов в строке
Напишите программу, которая удаляет все пробелы из введенной строки.
