Задача 1: Сумма элементов массива +
Задача: Напишите программу, которая пользователь вводит элементы, а затем выводит сумму всех элементов массива.

Задача 2: Среднее значение элементов массива
Задача: Напишите программу, которая вычисляет среднее арифметическое всех элементов массива.

Задача 3: Поиск элемента в массиве
Задача: Напишите программу, которая ищет заданное пользователем число в массиве и выводит его индекс, если оно найдено. Если число не найдено, программа должна вывести соответствующее сообщение.

Задача 4: Реверс массива +
Задача: Напишите программу, которая меняет порядок элементов массива на обратный (реверсирует массив).

Задача 5: Слияние двух массивов
Задача: Напишите программу, которая сливает два массива в один. Пользователь вводит два массива, а программа объединяет их элементы в новый массив.

Задача 6: Подсчёт количества положительных, отрицательных и нулевых элементов массива
Задача: Напишите программу, которая подсчитывает количество положительных, отрицательных и нулевых элементов в массиве.

Задача 7: Подсчёт чётных и нечётных чисел в массиве
Задача: Напишите программу, которая подсчитывает количество чётных и нечётных чисел в массиве.
