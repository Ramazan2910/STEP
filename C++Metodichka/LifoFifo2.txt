FIFO (First-In-First-Out) - это принцип организации данных, при котором элементы обрабатываются в порядке их поступления. Это означает, что элементы, добавленные раньше, будут извлечены и обработаны раньше всех остальных.

В контексте программирования на C++ FIFO может быть реализована с использованием структуры данных, такой как очередь (queue). В стандартной библиотеке C++ предусмотрен контейнер std::queue, который обеспечивает реализацию FIFO.

Пример использования std::queue:

#include <iostream>
#include <queue>

int main() {
    // Создаем пустую очередь целых чисел
    std::queue<int> fifo;

    // Добавляем элементы в очередь
    fifo.push(10);
    fifo.push(20);
    fifo.push(30);

    // Извлекаем элементы из очереди и выводим на экран
    while (!fifo.empty()) {
        std::cout << fifo.front() << " "; // Выводим первый элемент
        fifo.pop(); // Удаляем первый элемент
    }

    return 0;
}

Этот код добавляет элементы 10, 20 и 30 в очередь и затем выводит их на экран. В результате получится вывод: 10 20 30. Обратите внимание, что элементы извлекаются из очереди в порядке их поступления, поэтому первым будет извлечен элемент 10, затем 20, и так далее.

Хорошо, вот более простой пример использования FIFO с помощью std::queue. Допустим, у нас есть некоторый процесс, который должен обработать несколько задач в порядке их поступления:


#include <iostream>
#include <queue>

int main() {
    // Создаем очередь для задач
    std::queue<int> tasks;

    // Добавляем задачи в очередь
    tasks.push(1);
    tasks.push(2);
    tasks.push(3);
    tasks.push(4);
    tasks.push(5);

    // Обрабатываем задачи в порядке их поступления
    while (!tasks.empty()) {
        // Получаем первую задачу из очереди
        int task = tasks.front();
        tasks.pop(); // Удаляем задачу из очереди

        // Обрабатываем задачу (в данном случае просто выводим ее на экран)
        std::cout << "Обрабатывается задача " << task << std::endl;
    }

    return 0;
}


Этот код создает очередь задач и добавляет в нее несколько задач (числа от 1 до 5). Затем он обрабатывает эти задачи в порядке их поступления, выводя каждую на экран. Важно отметить, что задачи обрабатываются в порядке FIFO: первая добавленная задача (1) будет обработана первой, затем вторая (2) и так далее.

#include <iostream>
#include <queue>
#include <string>

int main() {
    // Создаем очередь студентов
    std::queue<std::string> students;

    // Студенты ожидают консультацию у преподавателя
    students.push("Анна");
    students.push("Иван");
    students.push("Мария");
    students.push("Петр");

    // Преподаватель начинает консультацию
    std::cout << "Преподаватель начинает консультацию:" << std::endl;

    // Обрабатываем студентов в порядке их поступления
    while (!students.empty()) {
        // Получаем следующего студента из очереди
        std::string student = students.front();
        students.pop(); // Удаляем студента из очереди

        // Обрабатываем консультацию
        std::cout << "Студент " << student << " получает консультацию." << std::endl;
    }

    // Консультация завершена
    std::cout << "Консультация завершена." << std::endl;

    return 0;
}

Этот код создает очередь студентов, которые ожидают консультацию у преподавателя. Затем преподаватель начинает консультацию и обрабатывает студентов в порядке их поступления. Когда все студенты обработаны, консультация завершается.

Очередь в C++ - это структура данных, которая работает по принципу FIFO (First-In-First-Out), что означает, что элементы добавляются в конец очереди и извлекаются из начала очереди.

В стандартной библиотеке C++ для работы с очередью предоставляется контейнер std::queue, который является адаптером над контейнером (по умолчанию std::deque, но можно указать и другой контейнер).

Основные операции с очередью:

push(): Добавляет элемент в конец очереди.
pop(): Удаляет элемент из начала очереди.
front(): Возвращает элемент из начала очереди (без удаления).
back(): Возвращает элемент из конца очереди (без удаления).
empty(): Проверяет, пуста ли очередь.
size(): Возвращает количество элементов в очереди.

#include <iostream>
#include <queue>

int main() {
    // Создаем пустую очередь целых чисел
    std::queue<int> q;

    // Добавляем элементы в очередь
    q.push(10);
    q.push(20);
    q.push(30);

    // Выводим первый элемент
    std::cout << "Первый элемент в очереди: " << q.front() << std::endl;

    // Удаляем первый элемент
    q.pop();

    // Выводим новый первый элемент
    std::cout << "Новый первый элемент в очереди: " << q.front() << std::endl;

    // Выводим последний элемент
    std::cout << "Последний элемент в очереди: " << q.back() << std::endl;

    // Выводим количество элементов в очереди
    std::cout << "Количество элементов в очереди: " << q.size() << std::endl;

    return 0;
}


Этот код создает очередь целых чисел и добавляет в нее три элемента. Затем он извлекает и выводит информацию о первом и последнем элементах очереди, а также о ее размере.

Как это работает в памяти:

std::deque:std::deque реализуется как массив блоков (chunks), каждый блок обычно имеет фиксированный размер (например, 8 или 16 элементов). Когда вы добавляете элементы в std::deque, они распределяются по блокам. При этом происходит выделение динамической памяти для новых блоков, когда существующие блоки заполняются.В данном примере каждый блок std::deque будет содержать элементы 10, 20 и 30.
std::queue:std::queue использует std::deque внутри себя. Он добавляет элементы в конец std::deque с помощью push() и извлекает их из начала с помощью pop().
