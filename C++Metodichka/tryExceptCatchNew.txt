Исключительные ситуации: понятие и необходимость обработки
Исключительная ситуация — это непредвиденное событие или ошибка, которая возникает во время выполнения программы и может нарушить её нормальное выполнение. Исключительные ситуации могут включать:

Деление на ноль.

Выход за пределы массива.

Попытку открытия несуществующего файла.

Ошибки переполнения или недостатка памяти и др.


Необходимость обработки исключительных ситуаций:

Исключения помогают отделить основной код от кода обработки ошибок, делая программу более читаемой.

Обработка исключений позволяет предотвратить завершение программы в случае ошибки, а вместо этого выполнить корректные действия для её разрешения или безопасного завершения.

Исключения дают возможность централизованно обрабатывать ошибки, вместо того чтобы проверять ошибки в каждом операторе.


Типы исключительных ситуаций в C++
Исключения в C++ могут быть разных типов:

Стандартные исключения: C++ предоставляет стандартные классы исключений в библиотеке <stdexcept>, такие как:

std::logic_error (ошибки логики, например, std::invalid_argument или std::out_of_range).
std::runtime_error (ошибки выполнения, такие как std::overflow_error, std::underflow_error).
Пользовательские исключения: разработчик может определить свои собственные классы исключений для обработки специфичных для программы ситуаций.

Исключения уровня ОС: возникают из-за сбоев в работе операционной системы, например, при нехватке ресурсов или ошибки доступа к памяти.


Базовые понятия обработки исключительных ситуаций в C++
В C++ исключения обрабатываются с помощью ключевых слов try, catch и throw.

1. Ключевое слово try
Блок try используется для оборачивания кода, в котором могут возникнуть исключительные ситуации. Если исключение возникает в блоке try, выполнение программы передаётся соответствующему блоку catch, который следует за ним.

try {
    // Код, который может вызвать исключение
}


2. Ключевое слово catch
Блок catch перехватывает и обрабатывает исключение, возникшее в блоке try. Блок catch принимает параметр, который определяет тип исключения, который он перехватывает.

catch (тип_исключения параметр) {
    // Код для обработки исключения
}


3. Ключевое слово throw
Ключевое слово throw используется для генерации исключения. Когда throw встречается, выполнение программы передаётся из блока try в соответствующий блок catch.

Синтаксис:

throw значение_исключения;


Можно использовать любой тип данных для исключений: стандартные классы, пользовательские классы или даже целые числа.

Примеры использования обработки исключительных ситуаций
Пример 1: Деление на ноль

#include <iostream>
using namespace std;

int divide(int a, int b) {
    if (b == 0)
        throw "Деление на ноль невозможно!";  // Генерируем исключение
    return a / b;
}

int main() {
    try {
        cout << "Результат: " << divide(10, 0) << endl;
    }
    catch (const char* e) {  // Перехватываем исключение
        cout << "Ошибка: " << e << endl;
    }
    return 0;
}


Объяснение: Функция divide проверяет, равен ли второй аргумент нулю. Если да, то она выбрасывает исключение с помощью throw. В блоке try вызывается divide, и если возникает исключение, оно перехватывается блоком catch, который выводит сообщение об ошибке.


Пример 2: Обработка стандартного исключения std::out_of_range

#include <iostream>
#include <vector>
#include <stdexcept>
using namespace std;

int main() {
    vector<int> numbers = {1, 2, 3};

    try {
        cout << numbers.at(5) << endl;  // Доступ за пределы вектора
    }
    catch (const out_of_range& e) {  // Перехват стандартного исключения
        cout << "Ошибка: " << e.what() << endl;
    }
    return 0;
}


Объяснение: В этом примере мы обращаемся к элементу вектора numbers по индексу 5, который не существует, что вызывает исключение std::out_of_range. Это исключение перехватывается блоком catch, и выводится сообщение ошибки.

На уровне памяти обработка исключений в C++ работает следующим образом:

1. Таблицы исключений и таблицы дескрипторов
Компиляторы C++ создают специальные структуры данных (таблицы исключений или таблицы дескрипторов) для хранения информации о том, где находятся блоки try, catch, и где программа должна оказаться, если произойдет исключение. Таблицы дескрипторов позволяют программе, встретив исключение, найти соответствующий блок catch, который должен обработать это исключение.

Эти таблицы создаются на этапе компиляции и хранятся в памяти, но используются только тогда, когда возникает исключение, что минимизирует накладные расходы при нормальной работе программы.


2. Стек вызовов и стековая раскрутка
Когда возникает исключение, программа выполняет так называемую стековую раскрутку (stack unwinding). Вот как это работает:

Стек вызовов содержит цепочку функций, которые были вызваны до текущего момента. Каждый вызов функции добавляет новый фрейм в стек, содержащий локальные переменные, указатели на следующий адрес возврата, и другую служебную информацию.

Когда генерируется исключение с помощью оператора throw, программа начинает искать блок catch, который сможет обработать это исключение. Для этого она начинает раскручивать стек — то есть, удалять из стека вызовы функций, пока не найдет нужный обработчик (блок catch), который соответствует типу исключения.

В процессе раскрутки, если у удаляемой функции есть локальные объекты, для них вызываются деструкторы, что освобождает память, занятую этими объектами.

Когда нужный блок catch найден, управление передается в него, и программа может обработать исключение.


3. Управление ресурсами и очистка памяти
Стековая раскрутка автоматически вызывает деструкторы для объектов, которые были созданы в рамках функции, откуда произошло исключение, а также для всех функций, которые находятся ниже в стеке вызовов. Это позволяет избежать утечек памяти и обеспечивает корректное освобождение ресурсов, таких как динамически выделенная память, файловые дескрипторы и т.д.

RAII (Resource Acquisition Is Initialization) — это важный принцип для управления ресурсами при исключениях. Благодаря ему, объекты освобождают ресурсы при разрушении. Например:

#include <iostream>
#include <stdexcept>

class Resource {
public:
    Resource() { std::cout << "Resource acquired\n"; }
    ~Resource() { std::cout << "Resource released\n"; }
};

void exampleFunction() {
    Resource res;
    throw std::runtime_error("Some error");
}

int main() {
    try {
        exampleFunction();
    }
    catch (const std::exception& e) {
        std::cout << "Caught exception: " << e.what() << std::endl;
    }
    return 0;
}


Здесь, когда возникает исключение, деструктор ~Resource будет вызван, и память, занятую этим объектом, будет освобождена, предотвращая утечки.

4. Накладные расходы на производительность
Механизм обработки исключений в C++ имеет определенные накладные расходы на производительность, связанные с созданием таблиц исключений и стековой раскруткой, однако они проявляются только при фактическом выбрасывании исключения. Если исключений не происходит, программа выполняется без дополнительных затрат на эти структуры.

catch в C++ используется для перехвата и обработки исключений, которые могут возникнуть при выполнении программы. Он работает в паре с блоком try, который содержит код, где может возникнуть ошибка, и ключевым словом throw, которое используется для генерации исключений.

Основные функции и особенности catch
Перехват исключений: Когда возникает исключение (например, деление на ноль, выход за пределы массива, ошибка при открытии файла), оно передается из блока try в блок catch. catch принимает исключение и предотвращает аварийное завершение программы.

Обработка ошибок и выполнение альтернативных действий: Внутри catch можно указать, как именно программа должна реагировать на исключение — вывести сообщение об ошибке, выполнить дополнительные действия для исправления, освободить ресурсы или выполнить другие меры по обработке.

Типобезопасная обработка: catch может перехватывать исключения разных типов (например, int, std::exception, пользовательские классы исключений и т.д.). Это позволяет точно определить, как обрабатывать разные типы ошибок. Например, можно обрабатывать отдельно ошибки логики и ошибки работы с ресурсами.

Синтаксис и пример работы catch

#include <iostream>
#include <stdexcept>
using namespace std;

void riskyFunction() {
    throw runtime_error("Произошла ошибка!");  // Генерация исключения
}

int main() {
    try {
        riskyFunction();  // Код, где может возникнуть исключение
    }
    catch (const runtime_error& e) {  // Перехват исключения
        cout << "Перехвачено исключение: " << e.what() << endl;
    }
    catch (...) {  // Обработка любых других исключений
        cout << "Неизвестная ошибка!" << endl;
    }
    return 0;
}


Как это работает
Вызов исключения: Функция riskyFunction генерирует исключение с помощью throw.
Перехват в блоке catch: catch перехватывает исключение и обрабатывает его. Здесь он выводит сообщение об ошибке, предотвращая аварийное завершение программы.
Перехват любых исключений: catch(...) позволяет перехватывать исключения любого типа, если конкретный тип не указан (полезно для универсальной обработки ошибок).
Использование нескольких блоков catch
Можно использовать несколько блоков catch для разных типов исключений:

try {
    // Код, где может произойти несколько типов ошибок
}
catch (const std::out_of_range& e) {
    cout << "Ошибка диапазона: " << e.what() << endl;
}
catch (const std::invalid_argument& e) {
    cout << "Неверный аргумент: " << e.what() << endl;
}
catch (...) {
    cout << "Произошла неизвестная ошибка." << endl;
}


Преимущества использования catch
Безопасность выполнения: программа продолжает выполнение после исключения.
Чистый и структурированный код: обработка ошибок отделена от основной логики.
Локализация и управление ошибками: блоки catch позволяют управлять и обрабатывать исключения по месту их возникновения, снижая риск утечек памяти и ошибок.
Итог
catch — это важный элемент для обработки ошибок, который позволяет разработчику безопасно и гибко реагировать на непредвиденные ситуации в программе, избегая её аварийного завершения.

Создание собственного класса исключений в C++ позволяет вам точно определить тип ошибок, которые могут возникнуть в программе, и предоставить детализированные сообщения об ошибках. Чтобы создать свой класс исключений, можно унаследоваться от стандартного класса std::exception или одного из его производных классов, таких как std::runtime_error или std::logic_error.

1. Создание простого пользовательского класса исключений
Вот пример, в котором создается класс MyException, наследующийся от std::exception, с переопределением метода what() для предоставления сообщения об ошибке:

#include <iostream>
#include <exception>  // Для std::exception

class MyException : public std::exception {
public:
    // Переопределяем метод what() для вывода пользовательского сообщения
    const char* what() const noexcept override {
        return "Произошла ошибка в программе: пользовательское исключение!";
    }
};

void riskyFunction() {
    throw MyException();  // Генерируем исключение типа MyException
}

int main() {
    try {
        riskyFunction();
    }
    catch (const MyException& e) {  // Перехватываем наше пользовательское исключение
        std::cout << "Перехвачено исключение: " << e.what() << std::endl;
    }
    return 0;
}


Что происходит:

Мы определяем класс MyException, который наследует от std::exception.
Переопределяем метод what(), чтобы вернуть пользовательское сообщение об ошибке.
В функции riskyFunction генерируем исключение типа MyException, которое затем перехватывается и обрабатывается в main.
2. Пользовательский класс исключений с сообщением
Часто бывает полезно, чтобы исключение передавало подробное сообщение о причине ошибки. Добавим конструктор, принимающий строку, и сохраним сообщение об ошибке в виде строки-члена.

#include <iostream>
#include <exception>
#include <string>

class MyException : public std::exception {
private:
    std::string errorMessage;  // Храним сообщение об ошибке

public:
    // Конструктор принимает сообщение об ошибке
    MyException(const std::string& message) : errorMessage(message) {}

    // Переопределение метода what()
    const char* what() const noexcept override {
        return errorMessage.c_str();  // Возвращаем сообщение как C-строку
    }
};

void riskyFunction() {
    throw MyException("Ошибка: недопустимая операция!");  // Генерируем исключение с сообщением
}

int main() {
    try {
        riskyFunction();
    }
    catch (const MyException& e) {
        std::cout << "Перехвачено исключение: " << e.what() << std::endl;
    }
    return 0;
}


Что происходит:

Мы определяем класс MyException, который наследует от std::exception.
Переопределяем метод what(), чтобы вернуть пользовательское сообщение об ошибке.
В функции riskyFunction генерируем исключение типа MyException, которое затем перехватывается и обрабатывается в main.
2. Пользовательский класс исключений с сообщением
Часто бывает полезно, чтобы исключение передавало подробное сообщение о причине ошибки. Добавим конструктор, принимающий строку, и сохраним сообщение об ошибке в виде строки-члена.

#include <iostream>
#include <exception>
#include <string>

class MyException : public std::exception {
private:
    std::string errorMessage;  // Храним сообщение об ошибке

public:
    // Конструктор принимает сообщение об ошибке
    MyException(const std::string& message) : errorMessage(message) {}

    // Переопределение метода what()
    const char* what() const noexcept override {
        return errorMessage.c_str();  // Возвращаем сообщение как C-строку
    }
};

void riskyFunction() {
    throw MyException("Ошибка: недопустимая операция!");  // Генерируем исключение с сообщением
}

int main() {
    try {
        riskyFunction();
    }
    catch (const MyException& e) {
        std::cout << "Перехвачено исключение: " << e.what() << std::endl;
    }

Что изменилось:

Конструктор MyException принимает std::string, которая описывает ошибку, и сохраняет её в приватном члене errorMessage.
what() возвращает это сообщение с помощью c_str().
Теперь при вызове riskyFunction исключение будет иметь более точное сообщение об ошибке.

3. Пользовательский класс исключений с дополнительной информацией
Для более сложных случаев можно добавить дополнительные данные в исключение, например, код ошибки или другую информацию.

#include <iostream>
#include <exception>
#include <string>

class MyException : public std::exception {
private:
    std::string errorMessage;
    int errorCode;

public:
    // Конструктор принимает сообщение об ошибке и код ошибки
    MyException(const std::string& message, int code)
        : errorMessage(message), errorCode(code) {}

    // Переопределение метода what()
    const char* what() const noexcept override {
        return errorMessage.c_str();
    }

    // Метод для получения кода ошибки
    int code() const noexcept {
        return errorCode;
    }
};

void riskyFunction() {
    throw MyException("Ошибка доступа к ресурсу", 404);  // Генерируем исключение с кодом ошибки
}

int main() {
    try {
        riskyFunction();
    }
    catch (const MyException& e) {
        std::cout << "Перехвачено исключение: " << e.what() << std::endl;
        std::cout << "Код ошибки: " << e.code() << std::endl;
    }
    return 0;
}


Что добавлено:

Поле errorCode хранит числовой код ошибки.
Метод code() возвращает код ошибки, что может быть полезно для более детальной обработки ошибок.

Создадим пользовательский класс исключения PersonException, который будет использоваться для обработки специфических ошибок, связанных с классом Person. Например, такие исключения могут возникать при создании объекта с некорректными данными, такими как возраст или имя.

Для примера создадим также базовый класс Person, у которого будут поля name и age. Исключение PersonException будет выбрасываться, если, например, возраст указан некорректно (меньше нуля или слишком велик).

Пример кода с классом Person и пользовательским исключением PersonException

#include <iostream>
#include <string>
#include <exception>

class PersonException : public std::exception {
private:
    std::string errorMessage;

public:
    // Конструктор принимает сообщение об ошибке
    PersonException(const std::string& message) : errorMessage(message) {}

    // Переопределение метода what() для возврата сообщения об ошибке
    const char* what() const noexcept override {
        return errorMessage.c_str();
    }
};

class Person {
private:
    std::string name;
    int age;

public:
    // Конструктор принимает имя и возраст
    Person(const std::string& name, int age) : name(name), age(age) {
        if (age < 0 || age > 120) {
            throw PersonException("Ошибка: возраст должен быть в диапазоне от 0 до 120");
        }
        if (name.empty()) {
            throw PersonException("Ошибка: имя не может быть пустым");
        }
    }

    void display() const {
        std::cout << "Имя: " << name << ", Возраст: " << age << std::endl;
    }
};

int main() {
    try {
        Person person("Alice", -5);  // Попытка создать объект с некорректным возрастом
        person.display();
    }
    catch (const PersonException& e) {
        std::cout << "Перехвачено исключение: " << e.what() << std::endl;
    }

    try {
        Person person("", 25);  // Попытка создать объект с пустым именем
        person.display();
    }
    catch (const PersonException& e) {
        std::cout << "Перехвачено исключение: " << e.what() << std::endl;
    }

    return 0;
}


Объяснение кода
Класс PersonException:

Наследуется от std::exception и переопределяет метод what(), который возвращает строку с сообщением об ошибке.
Конструктор класса принимает строку message, которая будет храниться как сообщение об ошибке. При вызове what() возвращается это сообщение.
Класс Person:

Имеет два поля: name и age.
В конструкторе проверяются значения аргументов name и age. Если age выходит за пределы допустимого диапазона или name пустое, генерируется исключение типа PersonException с соответствующим сообщением.
Метод display() выводит информацию о человеке.
Функция main:

Преимущества подхода
Этот подход позволяет управлять ошибками создания и использования объектов класса Person, делая код более безопасным и легко поддерживаемым. Теперь ошибки, специфичные для работы с классом Person, обрабатываются централизованно через класс PersonException.

Давайте создадим более простой пример класса Person и исключения PersonException. В этом примере класс Person будет иметь только поле age, и исключение будет выбрасываться, если возраст указан неправильно (например, меньше 0 или больше 150).

Простой пример: Person и PersonException

#include <iostream>
#include <exception>
#include <string>

// Класс для пользовательского исключения
class PersonException : public std::exception {
private:
    std::string errorMessage;

public:
    // Конструктор принимает сообщение об ошибке
    PersonException(const std::string& message) : errorMessage(message) {}

    // Переопределение метода what(), чтобы вернуть сообщение об ошибке
    const char* what() const noexcept override {
        return errorMessage.c_str();
    }
};

// Класс Person
class Person {
private:
    int age;

public:
    // Конструктор принимает возраст
    Person(int age) {
        if (age < 0 || age > 150) {
            throw PersonException("Ошибка: возраст должен быть от 0 до 150");
        }
        this->age = age;
    }

    void display() const {
        std::cout << "Возраст: " << age << " лет" << std::endl;
    }
};

int main() {
    try {
        Person person(-5);  // Некорректный возраст
        person.display();
    }
    catch (const PersonException& e) {
        std::cout << "Перехвачено исключение: " << e.what() << std::endl;
    }

    try {
        Person person(30);  // Корректный возраст
        person.display();
    }
    catch (const PersonException& e) {
        std::cout << "Перехвачено исключение: " << e.what() << std::endl;
    }

    return 0;
}


Объяснение
Класс PersonException:

Создан для обработки ошибок, связанных с классом Person.
Содержит errorMessage и переопределяет метод what(), чтобы вернуть это сообщение, когда происходит ошибка.
Класс Person:

Имеет только одно поле age.
В конструкторе проверяется значение age. Если возраст меньше 0 или больше 150, выбрасывается исключение PersonException.
В функции main:

В первой попытке создается Person с некорректным возрастом (-5), что вызывает исключение.
Во второй попытке создается Person с корректным возрастом (30), и выводится информация о возрасте.
Пример вывода

Перехвачено исключение: Ошибка: возраст должен быть от 0 до 150
Возраст: 30 лет
Этот пример проще и показывает основную идею: если возраст выходит за пределы допустимого диапазона, выбрасывается исключение, которое затем перехватывается и обрабатывается.

Вот краткий обзор каждой из этих тем, связанных с обработкой исключений в C++:

1. Понятие необработанного исключения
Необработанное исключение — это исключение, которое было выброшено, но не было перехвачено никаким блоком catch. Такое исключение приводит к аварийному завершению программы, так как C++ не имеет возможности продолжить выполнение кода.

#include <iostream>
#include <stdexcept>

void func() {
    throw std::runtime_error("Ошибка!");  // Исключение выбрасывается, но не обрабатывается
}

int main() {
    func();  // Без блока try-catch программа завершится аварийно
    return 0;
}


2. Специальная форма catch(...)
catch(...) — это универсальный блок catch, который может перехватить любое исключение, независимо от его типа. Используется, когда тип исключения заранее неизвестен или для "резервной" обработки исключений.

try {
    throw 10;  // Генерируем исключение типа int
}
catch (...) {  // Перехватываем любое исключение
    std::cout << "Произошло неизвестное исключение" << std::endl;
}


3. Исключения и функции
Исключения могут генерироваться как внутри функций, так и передаваться через них в вызывающий код, если они не обрабатываются локально. Таким образом, функция может передать возникшую ошибку вызывающему коду, где она может быть перехвачена.

void riskyFunction() {
    throw std::runtime_error("Ошибка в riskyFunction");
}

int main() {
    try {
        riskyFunction();  // Исключение передается на уровень main
    }
    catch (const std::exception& e) {
        std::cout << e.what() << std::endl;
    }
    return 0;
}


4. Описание списка исключений, генерируемых функцией
В старом стандарте C++ (до C++11) можно было указывать список исключений, которые может генерировать функция, с помощью спецификации throw(). В современных версиях C++ рекомендуется вместо этого использовать noexcept, чтобы указать, что функция не выбрасывает исключений.

void myFunc() noexcept {
    // Эта функция гарантированно не выбрасывает исключений
}


5. Раскрутка стека вызовов
Когда исключение генерируется, механизм исключений C++ начинает "раскручивать" стек вызовов. Это значит, что функции начинают завершаться в обратном порядке, и вызываются деструкторы локальных объектов до тех пор, пока не будет найден подходящий обработчик исключений. Если ни один обработчик не найден, программа завершится аварийно.

6. Повторная генерация исключения
Внутри блока catch можно использовать throw без аргументов, чтобы повторно выбросить текущее исключение на более высокий уровень стека вызовов.

void func() {
    try {
        throw std::runtime_error("Ошибка");
    }
    catch (...) {
        std::cout << "Повторная генерация исключения" << std::endl;
        throw;  // Повторная генерация текущего исключения
    }
}


7. Построение иерархии пользовательских классов исключений
Иерархия исключений позволяет группировать исключения по типам для более точной обработки. Например, создать базовый класс MyException и от него унаследовать классы FileException и NetworkException.



class MyException : public std::exception {};
class FileException : public MyException {};
class NetworkException : public MyException {};



8. Стандартный класс exception и его потомки
C++ предоставляет стандартные классы исключений, такие как std::exception, std::runtime_error, std::logic_error, std::bad_alloc и др. Все они наследуются от базового класса std::exception и поддерживают метод what(), который возвращает строку с сообщением об ошибке.

9. Обработка ошибок при выделении памяти
Если оператор new не может выделить память, он выбрасывает исключение std::bad_alloc. Это позволяет обрабатывать ошибки выделения памяти с помощью блока catch.

try {
    int* arr = new int[1000000000000];  // Попытка выделить слишком много памяти
}
catch (const std::bad_alloc& e) {
    std::cout << "Ошибка выделения памяти: " << e.what() << std::endl;
}


10. Обработка не пойманных и неожидаемых исключений
Если исключение не было поймано, вызывается стандартная функция std::terminate, которая завершает программу. Можно определить собственные обработчики для непойманных и неожидаемых исключений с помощью std::set_terminate() и std::set_unexpected().

#include <iostream>
#include <exception>

void myTerminate() {
    std::cout << "Непойманное исключение, завершение программы!" << std::endl;
    std::abort();
}

int main() {
    std::set_terminate(myTerminate);

    throw 10;  // Генерация необработанного исключения

    return 0;
}

Этот код устанавливает myTerminate как пользовательскую функцию для обработки необработанных исключений.
