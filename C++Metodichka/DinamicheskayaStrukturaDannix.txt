Динамические структуры Данных:

Динамические структуры данных — это структуры, которые позволяют эффективно управлять памятью, добавлять и удалять элементы в процессе выполнения программы. Они особенно полезны, когда заранее неизвестен объем данных или когда данные подлежат частым изменениям. Рассмотрим основные типы динамических структур данных, как они работают в памяти, их преимущества, недостатки, а также примеры реализации на C++.

Основные типы динамических структур данных
Связанный список (Linked List)
Двусвязный список (Doubly Linked List)
Стек (Stack)
Очередь (Queue)
Деревья (Trees)
Графы (Graphs)
Хеш-таблицы (Hash Tables)

Stack:

Lifo стек в C++ обычно реализуется с использованием контейнера std::stack, который предоставляет абстракцию стека поверх другого контейнера, такого как вектор, список или дек.


#include <iostream>
#include <stack>

int main() {
    std::stack<int> lifoStack; // Создаем пустой lifo стек

    // Помещаем элементы в стек
    lifoStack.push(10);
    lifoStack.push(20);
    lifoStack.push(30);

    // Печатаем верхний элемент стека (без удаления)
    std::cout << "Top element: " << lifoStack.top() << std::endl;

    // Удаляем верхний элемент из стека
    lifoStack.pop();

    // Печатаем размер стека
    std::cout << "Stack size: " << lifoStack.size() << std::endl;

    // Печатаем и удаляем оставшиеся элементы стека
    while (!lifoStack.empty()) {
        std::cout << "Element: " << lifoStack.top() << std::endl;
        lifoStack.pop();
    }

    return 0;
}

Этот код создает lifo стек с помощью std::stack, добавляет в него несколько элементов, удаляет верхний элемент и печатает оставшиеся элементы в порядке LIFO (последним пришел, первым вышел).

В данном примере std::stack использует контейнер по умолчанию, который по умолчанию является std::deque (двунаправленный динамический массив). Однако, вы можете явно указать другой контейнер в качестве параметра шаблона std::stack, если хотите использовать другую реализацию стека.

Стек (или LIFO - Last In, First Out) - это абстрактная структура данных, в которой элементы добавляются и удаляются только с одного конца, называемого "вершиной стека". Элемент, добавленный последним (последний пришел), будет удален первым (первый ушел).


• Интерфейс:

• push(x): Добавляет элемент x на вершину стека.

• pop(): Удаляет верхний элемент стека, не возвращая его значение.

• top(): Возвращает значение верхнего элемента стека, не удаляя его.

• empty(): Возвращает true, если стек пуст, и false в противном случае.

• size(): Возвращает количество элементов в стеке.

На уровне памяти стек обычно реализуется с использованием области памяти, называемой стеком вызовов (call stack). Стек вызовов хранит информацию о вызовах функций в программе, а также локальные переменные и временные данные.

Вот как работает стек вызовов на уровне памяти:

• Создание стека вызовов:

• При запуске программы операционная система выделяет область памяти для стека вызовов.

• Функции и вызовы:

• Каждый раз, когда функция вызывается, информация о вызове помещается в стек вызовов.

• Для каждого вызова функции создается новый фрейм стека (stack frame), который содержит:

• Адрес возврата: адрес в памяти, куда должен вернуться управление после завершения функции.

• Локальные переменные: переменные, объявленные внутри функции.

• Аргументы функции: значения, переданные в функцию при ее вызове.

• Другие временные данные.

• Добавление и удаление фреймов:

• При вызове новой функции фрейм функции добавляется в верхнюю часть стека.

• При завершении функции ее фрейм удаляется из верхней части стека, освобождая память.

• Работа с локальными переменными:

• Локальные переменные функции хранятся внутри соответствующего фрейма стека.

• При каждом обращении к локальной переменной используется смещение относительно указателя стека.


• Добавление и удаление фреймов:

• При вызове новой функции фрейм функции добавляется в верхнюю часть стека.

• При завершении функции ее фрейм удаляется из верхней части стека, освобождая память.
• Работа с локальными переменными:

• Локальные переменные функции хранятся внутри соответствующего фрейма стека.

• При каждом обращении к локальной переменной используется смещение относительно указателя стека.

• Оптимизации:

• Компиляторы могут использовать оптимизации, чтобы сократить объем памяти, занимаемый стеком. Например, оптимизация tail call elimination позволяет переиспользовать фрейм стека при определенных условиях.

• Границы стека:

• Стек вызовов обычно имеет ограниченный размер, определяемый операционной системой или компилятором.

• При превышении лимита размера стека возникает переполнение стека (stack overflow).

Рассмотрим пример кода и его соответствующего стека вызовов:

#include <iostream>

void functionB(int x) {
    int y = x * x;
    std::cout << "B: " << y << std::endl;
}

void functionA(int x) {
    int y = x + 1;
    std::cout << "A: " << y << std::endl;
    functionB(y);
}

int main() {
    functionA(5);
    return 0;
}


При выполнении этого кода создается следующий стек вызовов:


       |              |
       | functionB(6) |
       |--------------|
       | functionA(5) |
main ->|--------------|
       |   (main)     |
       |--------------|
       |              |
       |              |
       |      .       |


При вызове functionA(5) добавляется фрейм для functionA, а при вызове functionB(y) добавляется фрейм для functionB. Когда функции завершаются, соответствующие фреймы удаляются из верхней части стека.

Давайте рассмотрим более подробно, как работает стек вызовов на уровне памяти:

• Структура данных:

• Стек вызовов - это структура данных типа LIFO (Last In, First Out), где последний добавленный элемент является первым, который будет удален.

• Во многих архитектурах стек вызовов растет в направлении уменьшения адресов памяти.


• Регистр указателя стека (Stack Pointer):

• Во время выполнения программы регистр указателя стека (SP) указывает на вершину стека.

• При добавлении элемента в стек значение SP уменьшается, а при удалении элемента значение SP увеличивается.

• Фреймы стека (Stack Frames):

• Каждая функция в программе имеет свой фрейм стека.

• Фрейм стека содержит информацию о вызове функции, включая локальные переменные, адрес возврата и другие данные.

• При вызове функции новый фрейм добавляется в верхушку стека, а при завершении функции фрейм удаляется из стека.


• Адрес возврата (Return Address):

• При вызове функции адрес возврата (return address) сохраняется на стеке.

• Этот адрес указывает на инструкцию, которая должна быть выполнена после завершения функции.

• Когда функция завершается, адрес возврата загружается из стека, чтобы управление вернулось к месту вызова.

• Аргументы функции:

• Параметры функции передаются через стек или через регистры в зависимости от соглашения о вызовах (calling convention).

• Если параметры передаются через стек, они помещаются на стек перед вызовом функции.

• Работа с локальными переменными:

• Локальные переменные функции хранятся в ее фрейме стека.

• Доступ к локальным переменным осуществляется через смещение относительно указателя стека.

• Стек и рекурсия:

• Рекурсивные функции могут привести к глубокому вложению фреймов стека.

• При глубокой рекурсии может произойти переполнение стека (stack overflow).

Реализация стека на основе массива: 

#include <iostream>
#define MAX 100

class Stack {
    int top;
    int arr[MAX];  // массив для хранения элементов стека

public:
    Stack() : top(-1) {}  // инициализация стека

    // Метод для добавления элемента в стек
    void push(int value) {
        if (top >= MAX - 1) {
            std::cout << "Stack Overflow" << std::endl;
            return;
        }
        arr[++top] = value;
    }

    // Метод для удаления элемента из стека
    int pop() {
        if (top < 0) {
            std::cout << "Stack Underflow" << std::endl;
            return -1;
        }
        return arr[top--];
    }

    // Метод для получения элемента с вершины стека
    int peek() {
        if (top < 0) {
            std::cout << "Stack is Empty" << std::endl;
            return -1;
        }
        return arr[top];
    }

    // Метод для проверки, пуст ли стек
    bool isEmpty() {
        return top < 0;
    }
};

int main() {
    Stack s;
    s.push(10);
    s.push(20);
    s.push(30);

    std::cout << "Top element: " << s.peek() << std::endl;
    std::cout << "Popped element: " << s.pop() << std::endl;
    std::cout << "Top element after pop: " << s.peek() << std::endl;

    return 0;
}


Объяснение кода
push: добавляет элемент в стек, если он не переполнен.
pop: удаляет элемент с вершины стека и возвращает его.
peek: возвращает текущий элемент с вершины стека без его удаления.
isEmpty: проверяет, пуст ли стек.



Реализация стека на основе связного списка:

#include <iostream>

struct Node {
    int data;
    Node* next;
    Node(int value) : data(value), next(nullptr) {}
};

class Stack {
    Node* top;

public:
    Stack() : top(nullptr) {}

    // Метод для добавления элемента в стек
    void push(int value) {
        Node* newNode = new Node(value);
        newNode->next = top;
        top = newNode;
    }

    // Метод для удаления элемента из стека
    int pop() {
        if (top == nullptr) {
            std::cout << "Stack Underflow" << std::endl;
            return -1;
        }
        int value = top->data;
        Node* temp = top;
        top = top->next;
        delete temp;
        return value;
    }

    // Метод для получения элемента с вершины стека
    int peek() {
        if (top == nullptr) {
            std::cout << "Stack is Empty" << std::endl;
            return -1;
        }
        return top->data;
    }

    // Метод для проверки, пуст ли стек
    bool isEmpty() {
        return top == nullptr;
    }

    ~Stack() {
        while (!isEmpty()) {
            pop();
        }
    }
};

int main() {
    Stack s;
    s.push(10);
    s.push(20);
    s.push(30);

    std::cout << "Top element: " << s.peek() << std::endl;
    std::cout << "Popped element: " << s.pop() << std::endl;
    std::cout << "Top element after pop: " << s.peek() << std::endl;

    return 0;
}


Объяснение кода
push: создает новый узел и устанавливает его в вершину стека.
pop: удаляет узел с вершины стека и возвращает его значение.
peek: возвращает значение вершины стека.
isEmpty: проверяет, пуст ли стек.




Стек — это структура данных, которая работает по принципу LIFO (Last In, First Out), где последний добавленный элемент выходит первым. Стек используется в программировании для решения задач, требующих временного хранения данных, где важно соблюдать обратный порядок извлечения. Рассмотрим, зачем и в каких условиях он используется.

1. Управление вызовами функций (стек вызовов)
В большинстве языков программирования при вызове функций используется стек для хранения адреса возврата, аргументов функции и локальных переменных. Когда функция завершает выполнение, стек позволяет вернуться к вызвавшему ее коду.

Пример: При рекурсивных вызовах каждая новая функция сохраняет свои данные в стеке, а после завершения последняя вызванная функция извлекается первой.
2. Реализация алгоритмов и структуры данных
Стек часто используется для создания других структур данных и алгоритмов:

Обратная Польская нотация (ОПН): Стек используется для вычисления математических выражений, записанных в ОПН, поскольку этот подход позволяет выполнять операции в нужном порядке.
Алгоритмы поиска в графах: Например, для поиска в глубину (DFS), стек помогает сохранить маршрут, позволяя откатиться обратно после завершения обхода ветвей.
3. Обработка скобочных выражений
Стек используется для проверки корректности вложенных скобок и структур, поскольку вложенные элементы должны быть закрыты в порядке, обратном их открытию.

Пример: При парсинге выражений (математических или программного кода) стек хранит открывающие скобки, и при встрече закрывающей скобки проверяется соответствие с вершиной стека.
4. Отмена действий (Undo/Redo)
Стек — отличная структура данных для реализации истории действий пользователя, таких как отмена и повтор операций (например, в текстовом редакторе).

Пример: В текстовом редакторе каждое действие добавляется в стек undo, и при отмене оно удаляется и перемещается в стек redo. Если пользователь использует redo, то действие снова добавляется в undo.
5. Обратный порядок элементов
Стек полезен, когда требуется вывести элементы в обратном порядке по сравнению с их добавлением.

Пример: При разворачивании строк или чисел. Стек позволяет легко инвертировать последовательность, например, реверсировать строку, добавляя символы по одному и затем извлекая их обратно.
6. Обработка и парсинг текста
При анализе и парсинге кода или текста, стек помогает управлять вложенными элементами, такими как HTML или XML-теги.

Пример: При парсинге HTML-документа открывающие теги помещаются в стек, и, встречая закрывающий тег, можно проверить, является ли он соответствующим последнему открытому тегу.
Преимущества использования стека:
Простота реализации: стеки легко создать и управлять ими.
Эффективное управление памятью: данные добавляются и удаляются с одной стороны, что делает операции более предсказуемыми.
Контроль последовательности действий: стек удобен для задач, где порядок данных важен, особенно когда важен порядок «последний пришел — первый вышел».
Когда не стоит использовать стек
Хотя стек имеет много применений, его не используют, когда:

Необходимо извлекать данные в произвольном порядке, так как стек работает только с верхним элементом.
Размер данных непредсказуем, так как стек может вызвать переполнение (Stack Overflow).
Стек — это мощная структура, когда нужен строгий порядок работы с данными, особенно для управления вызовами функций, отмены операций и алгоритмов, требующих обратного порядка действий.

Очередь в C++ можно реализовать с использованием массива или связного списка. Основная особенность очереди заключается в принципе FIFO (First In, First Out), где первый добавленный элемент выходит первым.

Реализация очереди с помощью массива:
#include <iostream>
#define MAX 100  // Максимальный размер очереди

class Queue {
    int front, rear;
    int arr[MAX];  // Массив для хранения элементов очереди

public:
    Queue() : front(-1), rear(-1) {}  // Инициализация очереди

    // Метод для добавления элемента в очередь
    void enqueue(int value) {
        if (rear == MAX - 1) {
            std::cout << "Queue Overflow" << std::endl;
            return;
        }
        if (front == -1) front = 0;  // Инициализация front на первом добавлении
        arr[++rear] = value;
    }

    // Метод для удаления элемента из очереди
    int dequeue() {
        if (front == -1 || front > rear) {
            std::cout << "Queue Underflow" << std::endl;
            return -1;
        }
        int value = arr[front];
        front++;
        if (front > rear) front = rear = -1;  // Очистка очереди, если все элементы извлечены
        return value;
    }

    // Метод для получения элемента в начале очереди
    int peek() {
        if (front == -1) {
            std::cout << "Queue is Empty" << std::endl;
            return -1;
        }
        return arr[front];
    }

    // Метод для проверки, пуста ли очередь
    bool isEmpty() {
        return front == -1;
    }
};

int main() {
    Queue q;
    q.enqueue(10);
    q.enqueue(20);
    q.enqueue(30);

    std::cout << "Front element: " << q.peek() << std::endl;
    std::cout << "Dequeued element: " << q.dequeue() << std::endl;
    std::cout << "Front element after dequeue: " << q.peek() << std::endl;

    return 0;
}



Объяснение кода
enqueue: добавляет элемент в конец очереди, если она не заполнена.
dequeue: удаляет элемент из начала очереди.
peek: возвращает элемент из начала очереди без его удаления.
isEmpty: проверяет, пуста ли очередь.



Реализация очереди с помощью связного списка:

#include <iostream>

struct Node {
    int data;
    Node* next;
    Node(int value) : data(value), next(nullptr) {}
};

class Queue {
    Node* front;
    Node* rear;

public:
    Queue() : front(nullptr), rear(nullptr) {}

    // Метод для добавления элемента в очередь
    void enqueue(int value) {
        Node* newNode = new Node(value);
        if (rear == nullptr) {
            front = rear = newNode;
            return;
        }
        rear->next = newNode;
        rear = newNode;
    }

    // Метод для удаления элемента из очереди
    int dequeue() {
        if (front == nullptr) {
            std::cout << "Queue Underflow" << std::endl;
            return -1;
        }
        int value = front->data;
        Node* temp = front;
        front = front->next;
        delete temp;

        if (front == nullptr) rear = nullptr;  // Очистка очереди, если пусто
        return value;
    }

    // Метод для получения элемента в начале очереди
    int peek() {
        if (front == nullptr) {
            std::cout << "Queue is Empty" << std::endl;
            return -1;
        }
        return front->data;
    }

    // Метод для проверки, пуста ли очередь
    bool isEmpty() {
        return front == nullptr;
    }

    ~Queue() {
        while (!isEmpty()) {
            dequeue();
        }
    }
};

int main() {
    Queue q;
    q.enqueue(10);
    q.enqueue(20);
    q.enqueue(30);

    std::cout << "Front element: " << q.peek() << std::endl;
    std::cout << "Dequeued element: " << q.dequeue() << std::endl;
    std::cout << "Front element after dequeue: " << q.peek() << std::endl;

    return 0;
}


Объяснение кода
enqueue: создает новый узел и добавляет его в конец очереди.
dequeue: удаляет узел из начала очереди и возвращает его значение.
peek: возвращает значение узла в начале очереди без удаления.
isEmpty: проверяет, пуста ли очередь.
Эти две реализации предоставляют базовую функциональность очереди и позволяют работать с элементами в режиме FIFO.

Односвязный список — это динамическая структура данных, состоящая из узлов, где каждый узел содержит данные и указатель на следующий узел. Он позволяет эффективно добавлять и удалять элементы в начале и конце списка, а также предоставляет гибкость с точки зрения управления памятью. Ниже приведены основные методы и пример кода на C++.

Основные операции:
Добавление элемента в начало списка (push_front).
Добавление элемента в конец списка (push_back).
Удаление элемента из начала списка (pop_front).
Удаление элемента из конца списка (pop_back).
Поиск и удаление узла по значению.

Реализация односвязного списка на C++

#include <iostream>

struct Node {
    int data;          // Данные узла
    Node* next;        // Указатель на следующий узел

    Node(int value) : data(value), next(nullptr) {}
};

class SinglyLinkedList {
private:
    Node* head;         // Указатель на первый элемент списка

public:
    SinglyLinkedList() : head(nullptr) {}

    // Добавление элемента в начало списка
    void push_front(int value) {
        Node* newNode = new Node(value);
        newNode->next = head;
        head = newNode;
    }

    // Добавление элемента в конец списка
    void push_back(int value) {
        Node* newNode = new Node(value);
        if (head == nullptr) {
            head = newNode;
            return;
        }
        Node* temp = head;
        while (temp->next != nullptr) {
            temp = temp->next;
        }
        temp->next = newNode;
    }

    // Удаление элемента из начала списка
    void pop_front() {
        if (head == nullptr) {
            std::cout << "List is empty\n";
            return;
        }
        Node* temp = head;
        head = head->next;
        delete temp;
    }

    // Удаление элемента из конца списка
    void pop_back() {
        if (head == nullptr) {
            std::cout << "List is empty\n";
            return;
        }
        if (head->next == nullptr) {
            delete head;
            head = nullptr;
            return;
        }
        Node* temp = head;
        while (temp->next->next != nullptr) {
            temp = temp->next;
        }
        delete temp->next;
        temp->next = nullptr;
    }

    // Поиск и удаление узла по значению
    void remove(int value) {
        if (head == nullptr) return;
        if (head->data == value) {
            pop_front();
            return;
        }
        Node* temp = head;
        while (temp->next != nullptr && temp->next->data != value) {
            temp = temp->next;
        }
        if (temp->next == nullptr) {
            std::cout << "Value not found in the list\n";
            return;
        }
        Node* toDelete = temp->next;
        temp->next = temp->next->next;
        delete toDelete;
    }

    // Вывод списка
    void print() {
        Node* temp = head;
        while (temp != nullptr) {
            std::cout << temp->data << " -> ";
            temp = temp->next;
        }
        std::cout << "nullptr\n";
    }

    // Деструктор для освобождения памяти
    ~SinglyLinkedList() {
        while (head != nullptr) {
            pop_front();
        }
    }
};

int main() {
    SinglyLinkedList list;

    list.push_back(10);
    list.push_back(20);
    list.push_front(5);
    list.print();  // Output: 5 -> 10 -> 20 -> nullptr

    list.pop_front();
    list.print();  // Output: 10 -> 20 -> nullptr

    list.push_back(30);
    list.push_back(40);
    list.remove(20);
    list.print();  // Output: 10 -> 30 -> 40 -> nullptr

    list.pop_back();
    list.print();  // Output: 10 -> 30 -> nullptr

    return 0;
}


Объяснение кода:
push_front: добавляет новый узел в начало списка.
push_back: добавляет новый узел в конец списка, используя проход по списку до последнего элемента.
pop_front: удаляет первый узел списка.
pop_back: удаляет последний узел списка.
remove: находит и удаляет первый узел с заданным значением.
print: выводит все элементы списка для визуализации.
Деструктор: удаляет все узлы при уничтожении списка, чтобы избежать утечек памяти.

Преимущества односвязного списка:
Гибкость с памятью: динамическое выделение памяти.
Эффективное добавление/удаление: проще и быстрее, чем в массиве, особенно если нужно вставить/удалить элементы в начале списка.
Недостатки:
Медленный доступ: нельзя обратиться к элементу по индексу, требуется проход по списку.
Дополнительная память: каждый узел занимает память для указателя next.







Рассмотрим пример односвязного списка, в котором хранятся данные о людях (класс Person). Каждый узел списка содержит объект Person с именем, возрастом и указателем на следующий узел.

Более подробное обьяснение данного кода: 

#include <iostream>
#include <string>

// Класс Person представляет человека с именем и возрастом
class Person {
public:
    std::string name;   // Имя человека
    int age;            // Возраст человека

    // Конструктор класса Person, инициализирующий имя и возраст
    Person(std::string name, int age) : name(name), age(age) {}
};

// Структура Node представляет узел списка, хранящий объект Person и указатель на следующий узел
struct Node {
    Person person;  // Объект Person, хранящий данные о человеке
    Node* next;     // Указатель на следующий узел списка

    // Конструктор, который инициализирует объект Person и устанавливает указатель next как nullptr
    Node(Person p) : person(p), next(nullptr) {}
};

// Класс PersonList представляет односвязный список персон
class PersonList {
private:
    Node* head;  // Указатель на первый узел списка (голову)

public:
    // Конструктор инициализирует head как nullptr, так как список пуст
    PersonList() : head(nullptr) {}

    // Метод добавляет новую персону в начало списка
    void addPersonFront(const Person& p) {
        Node* newNode = new Node(p); // Создаем новый узел с данными p
        newNode->next = head;        // Новый узел указывает на текущую голову
        head = newNode;              // Новый узел становится новой головой списка
    }

    // Метод добавляет новую персону в конец списка
    void addPersonBack(const Person& p) {
        Node* newNode = new Node(p); // Создаем новый узел с данными p
        if (head == nullptr) {       // Если список пуст
            head = newNode;          // Новый узел становится головой списка
            return;
        }
        Node* temp = head;           // Временный указатель для обхода списка
        while (temp->next != nullptr) { // Проходим до последнего узла
            temp = temp->next;
        }
        temp->next = newNode;        // Последний узел теперь указывает на новый узел
    }

    // Метод удаляет персону из списка по имени
    void removePersonByName(const std::string& name) {
        if (head == nullptr) return;       // Если список пуст, ничего не делаем
        if (head->person.name == name) {   // Если удаляемая персона - первая в списке
            Node* toDelete = head;         // Запоминаем текущую голову для удаления
            head = head->next;             // Голова теперь указывает на следующий узел
            delete toDelete;               // Удаляем старую голову
            return;
        }
        Node* temp = head;                 // Временный указатель для обхода списка
        while (temp->next != nullptr && temp->next->person.name != name) {
            temp = temp->next;             // Ищем узел перед удаляемым
        }
        if (temp->next == nullptr) {       // Если узел с именем не найден
            std::cout << "Person not found\n";
            return;
        }
        Node* toDelete = temp->next;       // Узел, который нужно удалить
        temp->next = temp->next->next;     // Обходим удаляемый узел
        delete toDelete;                   // Удаляем узел
    }

    // Метод ищет персону в списке по имени
    void findPersonByName(const std::string& name) {
        Node* temp = head;                 // Временный указатель для обхода списка
        while (temp != nullptr) {
            if (temp->person.name == name) { // Если имя найдено
                std::cout << "Found: " << temp->person.name << ", Age: " << temp->person.age << std::endl;
                return;
            }
            temp = temp->next;             // Переход к следующему узлу
        }
        std::cout << "Person not found\n"; // Сообщение, если персона не найдена
    }

    // Метод выводит всех персон в списке
    void printList() {
        Node* temp = head;                 // Временный указатель для обхода списка
        while (temp != nullptr) {
            std::cout << "Name: " << temp->person.name << ", Age: " << temp->person.age << " -> ";
            temp = temp->next;
        }
        std::cout << "nullptr\n";          // Выводим nullptr, когда достигаем конца списка
    }

    // Деструктор освобождает память, удаляя каждый узел списка
    ~PersonList() {
        while (head != nullptr) {          // Пока список не пуст
            Node* temp = head;             // Временная переменная для удаления текущей головы
            head = head->next;             // Перемещаем голову на следующий узел
            delete temp;                   // Удаляем старую голову
        }
    }
};

// Точка входа в программу
int main() {
    PersonList list;                       // Создаем пустой список персон

    // Добавляем персоны в список
    list.addPersonBack(Person("Alice", 30));  // Добавляем в конец
    list.addPersonBack(Person("Bob", 25));    // Добавляем в конец
    list.addPersonFront(Person("Eve", 22));   // Добавляем в начало

    list.printList();  // Вывод списка: Name: Eve, Age: 22 -> Name: Alice, Age: 30 -> Name: Bob, Age: 25 -> nullptr

    // Поиск по имени
    list.findPersonByName("Alice");  // Output: Found: Alice, Age: 30
    list.findPersonByName("Charlie"); // Output: Person not found

    // Удаление по имени
    list.removePersonByName("Bob");
    list.printList();  // Вывод списка после удаления: Name: Eve, Age: 22 -> Name: Alice, Age: 30 -> nullptr

    return 0;
}
