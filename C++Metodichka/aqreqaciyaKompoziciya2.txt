Агрегация и композиция - это два основных способа установления отношений между объектами в объектно-ориентированном программировании. Оба способа описывают, как один объект может содержать другой объект в своей структуре, но имеют различия в том, как эти объекты связаны и как их жизненный цикл управляется.

Агрегация:
Это отношение "имеет". Объект A имеет объекты типа B.
Объекты могут существовать независимо друг от друга.
Объекты могут быть связаны с несколькими объектами одного типа.
У объекта-владельца (объекта, который содержит другой объект) нет прямого контроля над жизненным циклом объекта, который он содержит. Объекты могут быть созданы и уничтожены независимо.
Пример: автомобиль и двигатель. У автомобиля может быть несколько двигателей, и двигатель может быть использован в разных автомобилях. Уничтожение автомобиля не означает автоматического уничтожения двигателя.
Композиция:
Это более строгое отношение "является частью". Объект A составляет часть объекта B.
Объекты живут и умирают вместе. Жизненный цикл владеющего объекта включает в себя жизненный цикл вложенных объектов.
Обычно представляет более сильное и более четкое отношение между объектами.
Пример: сердце и человек. Сердце является неотъемлемой частью человека. Когда человек умирает, сердце тоже умирает.

#include <iostream>
#include <string>

// Класс Engine представляет двигатель
class Engine {
public:
    std::string type; // Тип двигателя

    // Конструктор для инициализации типа двигателя
    Engine(const std::string& t) : type(t) {}
};

// Класс Car представляет автомобиль
class Car {
public:
    std::string model; // Модель автомобиля
    Engine* engine;    // Указатель на объект Engine - это пример агрегации

    // Конструктор для инициализации модели и двигателя автомобиля
    Car(const std::string& m, Engine* e) : model(m), engine(e) {}
};

int main() {
    // Создаем объект Engine, представляющий тип двигателя "Diesel"
    Engine engine("Diesel");

    // Создаем объект Car, представляющий модель "SUV" и агрегирующий объект Engine
    Car car("SUV", &engine);
    
    return 0;
}


В классе Car есть указатель Engine* engine, который указывает на объект Engine.
Объект Car агрегирует (содержит) объект Engine.
Объект Car и объект Engine могут существовать независимо друг от друга.
При уничтожении объекта Car, объект Engine остается нетронутым, так как он был передан как указатель и существует независимо от объекта Car.

Композиция:

#include <iostream>
#include <string>

class Heart {
public:
    std::string type;
    Heart(const std::string& t) : type(t) {}
};

class Human {
public:
    std::string name;
    Heart* heart; // Объект Human владеет объектом Heart
    Human(const std::string& n, const std::string& heartType) : name(n) {
        heart = new Heart(heartType);
    }
    ~Human() {
        delete heart;
    }
};

int main() {
    Human human("John", "Healthy");
    
    return 0;
}

#include <iostream>
#include <string>

// Класс Heart представляет сердце
class Heart {
public:
    std::string type; // Тип сердца

    // Конструктор для инициализации типа сердца
    Heart(const std::string& t) : type(t) {}
};

// Класс Human представляет человека
class Human {
public:
    std::string name; // Имя человека
    Heart* heart;     // Указатель на объект Heart - это пример композиции

    // Конструктор для инициализации имени человека и создания его сердца
    Human(const std::string& n, const std::string& heartType) : name(n) {
        // Создаем объект Heart внутри конструктора Human
        heart = new Heart(heartType);
    }

    // Деструктор для освобождения памяти, выделенной для сердца
    ~Human() {
        delete heart;
    }
};

int main() {
    // Создаем объект Human с именем "John" и сердцем "Healthy"
    Human human("John", "Healthy");
    
    return 0;
}



В классе Human есть указатель Heart* heart, который указывает на объект Heart.
Объект Human композирует (владеет) объект Heart.
Объект Heart создается внутри конструктора Human и уничтожается в деструкторе Human.
При уничтожении объекта Human, объект Heart также уничтожается, так как он является частью объекта Human и не может существовать независимо.

Агрегация:

#include <iostream>
#include <string>

// Класс Book представляет книгу
class Book {
public:
    std::string title;
    std::string author;

    Book(const std::string& t, const std::string& a) : title(t), author(a) {}
};

// Класс Library представляет библиотеку
class Library {
public:
    std::string name;
    Book* books[100]; // Массив указателей на книги - это пример агрегации

    Library(const std::string& n) : name(n) {
        for (int i = 0; i < 100; ++i) {
            books[i] = nullptr;
        }
    }

    // Метод для добавления книги в библиотеку
    void addBook(Book* book, int index) {
        if (index >= 0 && index < 100) {
            books[index] = book;
        }
    }
};

int main() {
    // Создаем объекты книг и библиотеки
    Book book1("The Great Gatsby", "F. Scott Fitzgerald");
    Book book2("To Kill a Mockingbird", "Harper Lee");
    Library library("City Library");

    // Добавляем книги в библиотеку
    library.addBook(&book1, 0);
    library.addBook(&book2, 1);

    return 0;
}

В C++ агрегация и композиция - это два основных способа установления отношений между объектами в объектно-ориентированном программировании. Эти отношения определяют, как один объект связан с другим и как их жизненный цикл управляется. Давайте рассмотрим каждый из них подробнее:

Агрегация:
Определение: Агрегация - это отношение между двумя классами, где один класс содержит другой как его часть, но эти классы могут существовать независимо друг от друга.
Пример: Класс A содержит объекты класса B. Объекты класса B не являются частью объекта класса A, а скорее связаны с ним. Класс A "имеет" объекты класса B.
Способ реализации: В C++ агрегация обычно реализуется с использованием указателей или ссылок на объекты другого класса.
Пример кода:

class B {};

class A {
public:
    B* b; // Агрегация - объект класса A содержит объект класса B
};


Жизненный цикл объектов: Объекты, связанные отношением агрегации, могут создаваться и уничтожаться независимо друг от друга. Уничтожение объекта A не влияет на объекты B, связанные с ним.
Композиция:
Определение: Композиция - это отношение между двумя классами, где один класс является частью другого, и их жизненный цикл связан. Объект одного класса не может существовать без объекта другого класса.
Пример: Класс A владеет объектами класса B и управляет их жизненным циклом. Объекты класса B "являются частью" объекта класса A.
Способ реализации: В C++ композиция обычно реализуется с помощью встраивания объектов в другой класс (прямо как члены класса).
Пример кода:

class B {};

class A {
public:
    B b; // Композиция - объект класса B является частью объекта класса A
};

Жизненный цикл объектов: Объекты, связанные отношением композиции, создаются и уничтожаются вместе с объектом, владеющим. Уничтожение объекта A также приводит к уничтожению объектов B, вложенных в него.
Важно помнить, что выбор между агрегацией и композицией зависит от того, каким образом связаны объекты и как управляется их жизненный цикл.
