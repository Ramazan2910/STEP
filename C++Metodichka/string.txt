Unicode является основным стандартом в области разработки программного обеспечения для работы с текстовыми данными, представленными на любом языке.

Unicode является именно стандартом, а не кодировкой, т.е. это таблица символов (кодовых точек), состоящая из 1114112 позиций, большинство из которых не заполнены. Это пространство разделено на 17 блоков, по 65 536 символов в каждом. Каждый блок включает определенную группу символов, например, в нулевом (базовом) блоке содержатся наиболее употребляемые символы всех современных алфавитов. В Unicode первые 128 кодовых точек совпадают с кодами таблицы ASCII

UTF (Unicode Transform Format) - это способ представления Unicode. Кодировки UTF определены стандартом Unicode и позволяют закодировать любой нужный нам кодовый пункт Unicode.


Существует несколько разных видов UTF-стандартов, которые отличаются количеством байтов, используемых для кодирования одного кодового пункта. В UTF-8 используется один байт на кодовый пункт, в UTF-16 - 2 байта, в UTF-32 - 4 байта.

Как уже было отмечено, UTF-8 использует для кода символа 1 байт (как и ASCII), т.е если программист при разработке программы использовал кодировку ASCII, а пользователи - UTF-8, то в отображении символов не будет никакой разницы.

В языке С++ под переменную типа char всегда выделяется объем памяти, равный 1 байту, т.е. поддерживаются только восьмибитные кодировки.

Для работы с 16-битными и 32-битными символами Unicode в C++11 были добавлены типы char16_t и char32_t. Пока у нас нет необходимости их использовать.


Как мы уже знаем, строка - это последовательность символов. А работа со строками в стиле языка C подразумевает их обработку как обычного массива символов. Такие строки также называют строки C-style.

Таким образом, строка - это массив, элементы которого имеют тип char. Однако, в отличие от обычных массивов, строка заканчивается специальным (завершающим) символом - нуль-терминатором ('\0'). Нуль-терминатор является признаком окончания строки, его ASCII -код равен 0.

Имя строки (также как и имя обычного массива) является указателем на его первый элемент (первый символ строки).

Объект типа string содержит последовательность символов типа char, которая может быть пустой. Например, определение пустой строки:

std::string message;

Также можно инициализировать или присвоить переменной string конкретную строку:


std::string message {"Hello world"};

std::string message2 = "Hello World";

std::string message3("Hello World");


С помощью стандартных потоков ввода и вывода cin и cout можно ввести данные в строку и вывести на консоль:


#include <iostream>

#include <string>

 

int main()

{   

    std::string name;

    std::cout << "Input your name: ";

    std::cin >> name;

    std::cout << "Your name: " << name << std::endl;

}



Чтобы считать всю строку вне зависимости от наличия пробелов, можно применять метод getline():


#include <iostream>
#include <string>

int main()

{   

    std::string name;

    std::cout << "Input your name: ";

    getline(std::cin, name);

    std::cout << "Your name: " << name << std::endl;

}

Метод getline принимает два объекта - std::cin и переменную, в которую надо считать строку.




При объявлении строки в квадратных скобках традиционно указываем максимальное число символов, которые будут в ней храниться (как при объявлении массива мы указывали максимальное число его элементов), учитывая при этом, что нам нужен еще один дополнительный элемент для нуль-терминатора в конце строки.

char myStr[6];

В этом примере строка myStr может содержать до пяти символов, т.к. последний (шестой) символ занимается нуль-терминатором.

Мы можем также выполнить инициализацию строки, задав в качестве начального значения последовательность символов в двойных кавычках:

char myStr[10] = "abcde";

В этом случае первые пять элементов строки - это коды указанных символов, а оставшиеся пять позиций будут содержать значения '\0'.



Если строка инициализируется, то необязательно указывать ее размер в квадратных скобках - можно «позволить» компилятору вычислить его автоматически на основе начального значения:

char myStr[] = "abcde";
В нашем примере длина строки (число элементов - символов) будет составлять шесть, т.к. C++ автоматически добавит нуль-терминатор в конец строки (т.е. нам не нужно добавлять его вручную).

После инициализации строки

char myStr[] = "abcde";

мы не можем присвоить ей новое значение:

myStr = "new value";



Взаимосвязь строк и указателей.

Имя строки (также, как и имя обычного массива) является указателем на его нулевой элемент (первый символ строки).

Поэтому мы можем объявить строку таким способом:

char* myStr;

В этом случае myStr является указателем на строку (фактически на первый ее элемент). Однако, память под строку при этом не выделяется (выделяется только под указатель). Поэтому данный подход не является рекомендуемым.

Мы можем также создать указатель на char и инициализировать его адресом первого символа другой строки (созданной, например, без использования указателей):

char myStr[] = "Welcome!"; char* strPtr = myStr; cout << strPtr << endl;

Обратите внимание, что ни в первом, ни во втором примере при использовании потокового вывода (cout <<) нам не нужно делать разыменование указателя (*strPtr). Это связано с особенностями работы оператора вывода в поток, который будет выводить строку символ за символом, начиная с указанного адреса, пока не достигнет конца строки (нуль-терминатора).


Чтобы с помощью указателя получить доступ ко второму символу строки, нам нужно передвинуть указатель на одну позицию вперед, начиная от начала строки:


char myStr[] = "Welcome!"; char* strPtr = myStr; cout <<"My string: "<< strPtr << endl; strPtr++; cout <<"2nd symbol of string is '"<< *strPtr <<"'.\n";



 Для того, чтобы вывести третий символ строки, нужно сместить указатель на две позиции вперед от начала строки и разыменовать его:

char myStr[] = "Welcome!"; char* strPtr = myStr; cout <<"My string: "<< strPtr << endl; cout <<"3-d symbol of string is '"<< *(strPtr+2) <<"'.\n";
