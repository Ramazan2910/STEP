const char* str = "Hello, C++!";
str[0] = 'J';  // Ошибка компиляции: нельзя изменять содержимое

Основы const char
const char указывает, что символ или строка не могут быть изменены.

Пример использования:
const char letter = 'A';  // Нельзя изменить значение 'letter'

------------------------------------

char buffer[20] = "Initial String";
buffer[0] = 'M';  // Можно изменять символы
std::cout << buffer << std::endl;  // Выведет "Mnitial String"


Удаление строки
Так как строковые литералы (const char*) в C++ хранятся в области памяти только для чтения, их удаление или освобождение памяти не требуется и, более того, попытки это сделать могут привести к ошибкам. Например:


const char* str = "Hello, world!";
// delete[] str;  // Ошибка: нельзя освобождать память строковых литералов
Однако если строка была динамически выделена с использованием оператора new, её нужно освободить с помощью оператора delete[]:


char* dynamicStr = new char[20];  // Выделяем память для 20 символов
strcpy(dynamicStr, "Dynamic String");

std::cout << dynamicStr << std::endl;

delete[] dynamicStr;  // Освобождаем выделенную память


 Копирование строк
Для работы с C-строками используются функции из стандартной библиотеки C, такие как strcpy и strcat (из <cstring>):


#include <iostream>
#include <cstring>

int main() {
    char buffer[50];
    const char* source = "Hello, C++!";
    
    // Копируем строку source в buffer
    strcpy(buffer, source);
    std::cout << "Копия: " << buffer << std::endl;

    return 0;
}

 Преобразование в std::string
Часто удобнее работать с классом std::string из стандартной библиотеки C++. Вы можете легко преобразовать const char* в std::string:


#include <iostream>
#include <string>

int main() {
    const char* cstr = "Hello, C++!";
    std::string str = cstr;  // Преобразование C-строки в std::string

    std::cout << str << std::endl;

    return 0;
}

Обратное преобразование также возможно:


std::string str = "Hello, C++!";
const char* cstr = str.c_str();  // Получение C-строки из std::string

Заключение
const char* используется для создания указателей на неизменяемые C-строки, которые нельзя модифицировать.
Массивы символов char[] могут быть изменяемыми, что позволяет заполнять и изменять строки.
Строковые литералы хранятся в области памяти только для чтения и не требуют ручного освобождения.
Для динамически выделенных строк (через new) память должна быть освобождена с помощью delete[].



1. Память и строковые литералы
Строковые литералы в C++ находятся в области памяти, предназначенной только для чтения. Это значит, что вы не можете изменять строки, на которые указывает const char*. Рассмотрим пример:


const char* str = "Hello, C++!";
В данном случае строка "Hello, C++!" хранится в статической памяти программы. Попытка изменения символов этой строки приведет к неопределенному поведению (обычно программе просто будет запрещено изменять эту область памяти, и произойдет ошибка). Поэтому строки, на которые указывает const char*, неизменяемы.

2. Массив символов char[] vs. const char*
Иногда можно спутать массивы символов и указатели на строковые литералы. Пример с массивом символов:


char str[] = "Hello, C++!";
str[0] = 'J';  // Это допустимо
std::cout << str << std::endl;  // Выведет "Jello, C++!"
Здесь строка объявлена как массив символов, и вы можете изменить отдельные символы в строке. Однако для строки, объявленной как const char*, такая операция вызовет ошибку:


const char* str = "Hello, C++!";
// str[0] = 'J';  // Ошибка: нельзя изменять строку

3. Передача const char* в функции
Если функция принимает строку как аргумент, вы можете передавать указатель на строку (const char*) или массив символов. Рассмотрим пример передачи строки в функцию:


void printMessage(const char* message) {
    std::cout << message << std::endl;
}

int main() {
    const char* str = "Hello, C++!";
    printMessage(str);  // Передаем строку в функцию
    return 0;
}
Здесь строка передается как указатель const char*. Важно отметить, что функция, которая принимает const char*, не может изменять содержимое строки, что помогает защитить данные от непреднамеренных изменений.

 Модификация строки через char*
Если вы хотите изменять строку, необходимо использовать указатель char* вместо const char*, либо создать динамический массив символов. Пример:


char buffer[] = "Hello, C++!";
buffer[0] = 'J';  // Изменяем первый символ
std::cout << buffer << std::endl;  // Выведет "Jello, C++!"
Если требуется динамическое выделение памяти для строки, используется оператор new:


char* dynamicStr = new char[20];  // Выделяем память для 20 символов
strcpy(dynamicStr, "Dynamic String");  // Копируем строку
dynamicStr[0] = 'M';  // Изменяем строку
std::cout << dynamicStr << std::endl;

delete[] dynamicStr;  // Освобождаем память



const char* может использоваться и с динамически выделенной памятью. Пример:


const char* dynamicStr = new char[20];
strcpy(const_cast<char*>(dynamicStr), "Hello, dynamic C++!");  // Копируем строку

std::cout << dynamicStr << std::endl;

delete[] dynamicStr;  // Освобождаем память
Однако важно понимать, что хотя const char* указывает на неизменяемую строку, сама память, на которую указывает указатель, может быть выделена динамически.

 Конкатенация C-строк
Для конкатенации C-строк (массивов символов или строковых литералов) можно использовать функцию strcat из библиотеки <cstring>:


#include <iostream>
#include <cstring>

int main() {
    char buffer[50] = "Hello, ";
    const char* world = "world!";
    strcat(buffer, world);  // Конкатенируем строки

    std::cout << buffer << std::endl;  // Выведет "Hello, world!"
    return 0;
}
Здесь строка world добавляется к строке, хранящейся в массиве buffer.

Сравнение строк
Для сравнения C-строк используется функция strcmp из <cstring>:



#include <iostream>
#include <cstring>

int main() {
    const char* str1 = "Hello";
    const char* str2 = "Hello";

    if (strcmp(str1, str2) == 0) {
        std::cout << "Строки равны" << std::endl;
    } else {
        std::cout << "Строки не равны" << std::endl;
    }

    return 0;
}
Функция strcmp возвращает 0, если строки одинаковы, и ненулевое значение, если строки отличаются.


 Преобразование строки в числа и обратно
Для преобразования C-строк в числа используются функции, такие как atoi (для целых чисел) и atof (для чисел с плавающей запятой):

const char* numStr = "123";
int num = atoi(numStr);  // Преобразование строки в int
std::cout << num << std::endl;  // Выведет 123
Для преобразования чисел обратно в строку можно использовать функцию sprintf:


char buffer[20];
int num = 123;
sprintf(buffer, "%d", num);  // Преобразование числа в строку
std::cout << buffer << std::endl;  // Выведет "123"


 Использование std::string вместо const char*
В современных проектах C++ часто предпочтительнее использовать класс std::string вместо const char*, так как он предоставляет удобный интерфейс для работы со строками, не требуя ручного управления памятью. Пример:


#include <iostream>
#include <string>

int main() {
    std::string str = "Hello, C++!";
    str[0] = 'J';  // Можно изменять содержимое строки
    std::cout << str << std::endl;  // Выведет "Jello, C++!"

    return 0;
}
Класс std::string предоставляет методы для конкатенации, поиска подстрок, изменения содержимого и т.д.

Однако, если нужно работать с C-API, которые ожидают const char*, вы можете получить C-строку из std::string с помощью метода .c_str():


std::string str = "Hello, C++!";
const char* cstr = str.c_str();  // Получаем указатель на C-строку
10. Заключение
Тип const char* широко используется в C++ для работы с неизменяемыми строками. Однако из-за ограничений (нельзя изменять содержимое строковых литералов, ручное управление памятью для динамических строк) класс std::string в большинстве случаев предпочтительнее для работы со строками в C++.
