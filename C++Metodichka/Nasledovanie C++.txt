Наследование в C++

Наследование — один из ключевых механизмов объектно-ориентированного программирования (ООП), позволяющий создавать новые классы на основе существующих. Этот механизм помогает избежать дублирования кода, расширять и изменять поведение существующих классов.

Основные понятия:

Базовый (родительский) класс: Это существующий класс, от которого наследуются свойства и методы.

Производный (дочерний) класс: Новый класс, который наследует свойства и методы базового класса.

Наследуемые члены: Производный класс наследует все открытые (public) и защищённые (protected) члены базового класса, но не наследует приватные (private) члены. Однако приватные члены могут быть доступны через функции-члены базового класса.


Типы наследования
Публичное наследование (public) — наиболее распространённый тип наследования. Все члены базового класса сохраняют свои уровни доступа в производном классе:

class Person {
public:
    std::string name;
protected:
    int age;
private:
    std::string ssn;  // social security number
};

class Employee : public Person {
public:
    void accessMembers() {
        name = "Alice";  // доступно
        age = 30;        // доступно
        // ssn = "123-45-6789";  // ошибка: ssn не доступен
    }
};




Защищённое наследование (protected) — члены базового класса, объявленные как public, становятся protected в производном классе:

class Student : protected Person {
public:
    void accessMembers() {
        name = "Bob";     // доступно, но теперь protected
        age = 20;         // доступно
    }
};




Приватное наследование (private) — все унаследованные члены базового класса становятся private в производном классе:

class Client : private Person {
public:
    void accessMembers() {
        name = "Eve";     // доступно, но теперь private
        age = 25;         // доступно
    }
};


Множественное наследование
Класс может наследовать от нескольких базовых классов. Это позволяет комбинировать функциональность из разных классов, но может привести к сложностям при разрешении конфликтов.


class ContactInfo {
public:
    std::string phone;
};

class JobInfo {
public:
    std::string company;
};

class Employee : public ContactInfo, public JobInfo {
public:
    void display() {
        std::cout << "Phone: " << phone << ", Company: " << company << std::endl;
    }
};


Наследование и память
Когда производный класс наследует базовый, объект производного класса включает в себя все поля базового класса. Например:

class Person {
    int id;  // 4 байта
};

class Employee : public Person {
    int salary;  // 4 байта
};


Объект Employee будет занимать 8 байт: 4 байта для поля id из класса Person и 4 байта для поля salary из класса Employee.

Виртуальные функции и полиморфизм
Виртуальные функции позволяют производным классам переопределять функции базового класса. Это основа для полиморфизма — возможности вызывать методы производного класса через указатели или ссылки на базовый класс.

class Person {
public:
    virtual void show() {
        std::cout << "Person class\n";
    }
};

class Employee : public Person {
public:
    void show() override {
        std::cout << "Employee class\n";
    }
};

int main() {
    Person* personPtr;
    Employee emp;
    personPtr = &emp;
    personPtr->show();  // Выведет "Employee class"
}




Конструкторы и деструкторы в наследовании
При создании объекта производного класса сначала вызывается конструктор базового класса, а затем конструктор производного класса. При удалении объекта сначала вызывается деструктор производного класса, а затем базового.

class Person {
public:
    Person() { std::cout << "Person constructor\n"; }
    ~Person() { std::cout << "Person destructor\n"; }
};

class Employee : public Person {
public:
    Employee() { std::cout << "Employee constructor\n"; }
    ~Employee() { std::cout << "Employee destructor\n"; }
};

int main() {
    Employee e;
}


Вывод:

Person constructor
Employee constructor
Employee destructor
Person destructor


Множественное наследование и память
Когда используется множественное наследование, память для каждого базового класса выделяется независимо:

class Person {
    int id;  // 4 байта
};

class ContactInfo {
    std::string phone;  // 24 байта (пример для 64-битной системы)
};

class Employee : public Person, public ContactInfo {
    int salary;  // 4 байта
};


Объект Employee будет занимать 32 байта (4 + 24 + 4 байта для полей базовых и производного классов).

Виртуальные функции и виртуальная таблица (vtable)
Когда объект класса содержит виртуальные функции, к его памяти добавляется указатель на виртуальную таблицу (vtable), которая содержит указатели на функции.

class Person {
public:
    virtual void show() { std::cout << "Person show\n"; }
};

class Employee : public Person {
public:
    void show() override { std::cout << "Employee show\n"; }
};


В объекте производного класса Employee будет дополнительно храниться указатель на виртуальную таблицу (vptr), которая обеспечивает полиморфизм.

Виртуальное наследование
Виртуальное наследование используется для предотвращения дублирования полей базового класса при множественном наследовании:

class Person {
public:
    int id;
};

class Manager : virtual public Person {};
class Engineer : virtual public Person {};

class Director : public Manager, public Engineer {};


В этом случае объект класса Director будет содержать только одну копию поля id из класса Person.

Заключение
Наследование в C++ предоставляет мощные механизмы для создания расширяемых и гибких классов, поддерживающих полиморфизм и повторное использование кода.

Наследование в C++ на уровне памяти работает через структурное объединение полей базового и производного классов, что позволяет производному классу иметь доступ к членам базового класса. Когда объект производного класса создаётся, его память содержит данные как для полей производного класса, так и для полей базового класса. Рассмотрим, как наследование работает на уровне памяти более углублённо.

1. Структура объекта в памяти
Когда производный класс наследует базовый, объект производного класса будет содержать поля базового класса в дополнение к своим собственным. Процесс распределения памяти происходит следующим образом:

Поля базового класса располагаются первыми в памяти.
Поля производного класса располагаются сразу за полями базового класса.
Пример:
class Base {
    int baseField1;  // 4 байта
    int baseField2;  // 4 байта
};

class Derived : public Base {
    int derivedField;  // 4 байта
};


В памяти объект класса Derived будет выглядеть так:

[ baseField1 | baseField2 | derivedField ]


Если объект класса Derived создаётся на стеке, компилятор выделяет память последовательно для полей baseField1, baseField2 и derivedField. Таким образом, объект Derived будет занимать 12 байт (при размере int равном 4 байтам).

2. Конструкторы и инициализация памяти
Когда объект производного класса создаётся, память для него выделяется целиком, включая память для членов базового класса. Конструкторы работают следующим образом:

Вызов конструктора базового класса:
При создании объекта сначала вызывается конструктор базового класса, который инициализирует его поля.
После этого вызывается конструктор производного класса, который инициализирует поля, специфичные для производного класса.
Например, при создании объекта класса Derived, будет вызван конструктор Base, который выделит и инициализирует память для baseField1 и baseField2. Затем конструктор Derived выделит память для derivedField.

class Base {
public:
    Base() { std::cout << "Base constructor\n"; }
    ~Base() { std::cout << "Base destructor\n"; }
};

class Derived : public Base {
public:
    Derived() { std::cout << "Derived constructor\n"; }
    ~Derived() { std::cout << "Derived destructor\n"; }
};

int main() {
    Derived d;
}



При выполнении этого кода:

Сначала выделяется память для объекта d.
Сначала вызывается конструктор Base, затем конструктор Derived.
При удалении объекта сначала вызывается деструктор Derived, а затем деструктор Base.
Это отражает принцип того, что сначала базовая часть объекта инициализируется и очищается.

3. Множественное наследование и память
В случае множественного наследования, когда производный класс наследует от нескольких базовых классов, память для объекта включает сегменты для каждого базового класса.

Пример множественного наследования:

class Base1 {
    int baseField1;  // 4 байта
};

class Base2 {
    int baseField2;  // 4 байта
};

class Derived : public Base1, public Base2 {
    int derivedField;  // 4 байта
};


В памяти объект класса Derived будет выглядеть так:

[ baseField1 (Base1) | baseField2 (Base2) | derivedField ]


В этом случае память для производного класса будет содержать объединённые поля обоих базовых классов. Объект Derived будет занимать 12 байт (если размер int — 4 байта).

4. Виртуальные функции и виртуальная таблица (vtable)
При использовании виртуальных функций, объект производного класса также хранит указатель на виртуальную таблицу (vtable), которая используется для реализации динамического полиморфизма. Эта таблица содержит указатели на функции, которые могут быть вызваны через базовый класс.

Когда объект класса содержит виртуальные функции, к его памяти добавляется указатель на таблицу виртуальных функций.

Пример с виртуальными функциями:

class Base {
public:
    virtual void show() { std::cout << "Base show\n"; }
};

class Derived : public Base {
public:
    void show() override { std::cout << "Derived show\n"; }
};


В объекте производного класса Derived будет дополнительно храниться указатель на виртуальную таблицу (vptr). Виртуальная таблица содержит указатели на функции show для каждого класса. В памяти объект Derived будет выглядеть так:

[ vptr | baseField | derivedField ]


vptr (указатель на таблицу виртуальных функций) хранит адрес таблицы с указателями на переопределённые методы.
При вызове виртуальной функции через указатель на базовый класс компилятор использует vptr, чтобы обратиться к правильной функции.
Виртуальная таблица (vtable) и её структура:
При использовании виртуальных функций для каждого класса создаётся своя vtable.
Если производный класс переопределяет виртуальные функции, vtable обновляется так, чтобы указывать на методы производного класса.
5. Виртуальное наследование
Виртуальное наследование используется для предотвращения проблем алмазного наследования, когда базовый класс наследуется через два или более промежуточных классов.

Пример:

class Base {
public:
    int baseField;
};

class Derived1 : virtual public Base {};

class Derived2 : virtual public Base {};

class MostDerived : public Derived1, public Derived2 {};


В этом случае объект класса MostDerived будет содержать только одну копию членов класса Base, так как использование виртуального наследования устраняет дублирование полей базового класса в памяти.

На уровне памяти компилятор создаёт сложную структуру, где указатели используются для разрешения виртуальных базовых классов, обеспечивая единственную копию полей класса Base.

6. Распределение памяти при наследовании
Объекты, создаваемые через наследование, имеют структуру, которая отражает базовый и производный классы:

Размер объекта зависит от числа и типов полей как базового, так и производного классов.
Указатель на виртуальные функции добавляет накладные расходы, если используются виртуальные функции.
Множественное наследование увеличивает размер объекта, так как память выделяется для каждого базового класса.
Заключение
На уровне памяти наследование в C++ подразумевает структурную организацию, при которой поля базового и производного классов объединяются в памяти. Основные аспекты работы наследования на уровне памяти включают:

Последовательное расположение полей базового и производного классов.
Инициализация и деструкция: сначала конструкторы базового класса, затем производного, а при удалении — наоборот.
Множественное наследование: память выделяется для каждого базового класса.
Виртуальные функции и vtable: при виртуальных функциях добавляется указатель на таблицу виртуальных функций, обеспечивая полиморфизм.
Виртуальное наследование помогает избежать дублирования базовых классов в памяти.
Этот механизм обеспечивает мощные возможности ООП в C++, позволяя организовать наследование и расширение классов без дублирования кода.

Продолжим углубленный анализ того, как работает механизм наследования в C++ на уровне памяти, обращая внимание на детали, которые касаются виртуальных методов, виртуального наследования, конструкторов и деструкторов, а также как различные аспекты наследования влияют на структуру объектов в памяти.

1. Виртуальные функции и vtable (виртуальная таблица методов)
Виртуальные функции обеспечивают полиморфизм в C++, позволяя использовать производные классы через указатели или ссылки на базовые классы. Для этого на уровне памяти используется структура, называемая виртуальной таблицей методов (vtable).

Виртуальная таблица методов (vtable)
Когда класс содержит хотя бы одну виртуальную функцию, компилятор создает специальную таблицу (vtable), которая содержит указатели на функции-члены. Для каждого объекта такого класса создается указатель на эту таблицу, называемый vptr. Этот указатель является скрытым членом каждого объекта класса и хранится в памяти как часть объекта. Когда вы вызываете виртуальную функцию через указатель на базовый класс, используется vptr для получения нужного указателя на функцию из vtable.

Как работает vtable:
Создание объекта: Когда создаётся объект класса с виртуальными функциями, в память записывается указатель vptr, который указывает на таблицу виртуальных методов (vtable).
Переопределение функций: Если производный класс переопределяет виртуальные функции, соответствующие записи в vtable обновляются так, чтобы указывать на функции производного класса.
Пример:

class Base {
public:
    virtual void show() { std::cout << "Base show\n"; }
};

class Derived : public Base {
public:
    void show() override { std::cout << "Derived show\n"; }
};


Структура памяти:
Base: будет содержать указатель vptr и методы базового класса.
Derived: также будет содержать свой указатель vptr, но его vtable будет включать переопределённый метод show из класса Derived.
Размеры объектов:
Когда виртуальные функции используются в классе, размер объекта увеличивается на размер одного указателя vptr. Этот указатель добавляется к уже существующим полям объекта. В большинстве современных архитектур размер указателя равен 4 байтам (на 32-битных системах) или 8 байтам (на 64-битных).

Таким образом, для класса Derived структура в памяти будет следующей:

[ vptr | поля базового класса | поля производного класса ]


Память под vptr выделяется независимо от количества виртуальных функций. Таблица vtable хранится отдельно от объектов и не является частью каждого объекта — это глобальная структура данных для всех экземпляров данного класса.

2. Виртуальное наследование и diamond problem
Виртуальное наследование используется для решения проблемы ромба (diamond problem), которая возникает, когда класс наследует несколько раз один и тот же базовый класс через промежуточные классы. В этом случае виртуальное наследование позволяет избежать дублирования полей базового класса.

class Base {
public:
    int value;
};

class Derived1 : virtual public Base {};
class Derived2 : virtual public Base {};

class Final : public Derived1, public Derived2 {};


Если использовать обычное наследование, то класс Final будет иметь две копии класса Base — одну через Derived1, и одну через Derived2. Это приводит к дублированию полей Base в памяти. Чтобы избежать этого, используется виртуальное наследование.

Как виртуальное наследование решает проблему:
При виртуальном наследовании создаётся только одна копия базового класса Base, даже если он наследуется через несколько промежуточных классов.
Компилятор добавляет дополнительные указатели в объекты классов для того, чтобы корректно обращаться к виртуально-наследуемым полям. Эти указатели указывают на единственную копию базового класса.
Влияние на память:
При виртуальном наследовании компилятор добавляет скрытые указатели для управления виртуальным базовым классом. Это увеличивает размер объектов, так как для каждого класса, использующего виртуальное наследование, требуется указатель на виртуальный базовый класс.

Пример:

class Final : public Derived1, public Derived2 {
    // Память для Final содержит только одну копию полей Base
};

В объекте класса Final будет одна копия полей из класса Base, и дополнительные указатели, необходимые для управления виртуальным наследованием.

3. Конструкторы, деструкторы и порядок инициализации
Инициализация полей в наследовании
Когда создаётся объект производного класса, сначала вызывается конструктор базового класса, а затем — конструктор производного класса. В результате сначала выделяется и инициализируется память для базовых членов, а затем — для членов производного класса.

Порядок вызова конструкторов:

Конструктор базового класса.
Конструктор производного класса.
При удалении объекта порядок вызова деструкторов противоположен:

Сначала вызывается деструктор производного класса.
Затем вызывается деструктор базового класса.
Пример:

class Base {
public:
    Base() { std::cout << "Base constructor\n"; }
    ~Base() { std::cout << "Base destructor\n"; }
};

class Derived : public Base {
public:
    Derived() { std::cout << "Derived constructor\n"; }
    ~Derived() { std::cout << "Derived destructor\n"; }
};

int main() {
    Derived d;
}


При выполнении этого кода вывод будет следующим:

Base constructor
Derived constructor
Derived destructor
Base destructor


Инициализация в памяти
При создании объекта сначала выделяется память для базовых членов, затем для членов производного класса.
При вызове конструктора базового класса эта часть памяти инициализируется, затем происходит инициализация производной части.
4. Память при множественном наследовании
Множественное наследование добавляет дополнительную сложность к распределению памяти. Когда производный класс наследует несколько базовых классов, объект этого производного класса включает память для каждого базового класса, как если бы они существовали независимо.

Пример множественного наследования:

class Base1 {
    int field1;
};

class Base2 {
    int field2;
};

class Derived : public Base1, public Base2 {
    int derivedField;
};


Объект Derived в памяти будет включать память для полей Base1, Base2 и для собственного поля derivedField. Структура объекта будет следующей:

[ поля Base1 | поля Base2 | поля Derived ]


Если классы имеют виртуальные функции, то каждый базовый класс будет содержать свой указатель vptr, что дополнительно увеличивает размер объекта.

5. Алгоритм распределения памяти и наследование
Когда создаётся объект производного класса, память для объекта выделяется в соответствии с рядом правил:

В первую очередь выделяется память для базовых классов.
Затем выделяется память для производного класса.
Если присутствуют виртуальные функции, добавляется указатель vptr для виртуальной таблицы.
Если используется виртуальное наследование, добавляются указатели для управления виртуальными базовыми классами.
Таким образом, распределение памяти для объектов производных классов зависит от:

Числа базовых классов.
Наличия виртуальных функций.
Наличия виртуального наследования.
Заключение
Наследование в C++ на уровне памяти — это сложный механизм, который управляется несколькими ключевыми аспектами:

Устройство объектов: Наследование влияет на структуру объектов, добавляя память для базовых классов в начале объекта и для производных — в конце.
Виртуальные функции: Если используются виртуальные функции, к объекту добавляется скрытый указатель vptr, а память выделяется для виртуальной таблицы.
Виртуальное наследование: Использование виртуального наследования позволяет избежать дублирования полей базового класса, но увеличивает сложность структуры объекта за счёт добавления указателей.
Множественное наследование: При множественном наследовании в объекте создаются независимые части памяти для каждого базового класса.
Инициализация памяти: Порядок вызова конструкторов и деструкторов управляет тем, как и когда выделяется и освобождается память для объектов классов.
Таким образом, понимание того, как работает наследование на уровне памяти, критично для оптимизации работы программы, особенно в системах с ограниченными ресурсами.
