Основы C++:

Каждая программа на языке С++ должна иметь как минимум одну функцию - функцию main(). Именно с этой функции начинается выполнение приложения. Ее имя main фиксировано и для всех программ на С++ всегда одинаково.

Программа C++ начинается с функции main(), которая является точкой входа в программу.

#include <iostream>               // подключаем заголовочный файл iostream
  
int main()                          // определяем функцию main
{                                   // начало функции
    std::cout << "Hello World!";   // выводим строку на консоль
    return 0;                       // выходим из функции
}                                   // конец функции


#include <iostream> - это директива препроцессора, которая включает в программу заголовочный файл <iostream>, необходимый для работы с потоками ввода/вывода.

int main() - это определение функции main(). Функция main() возвращает целочисленное значение (int) и не принимает аргументов.

{ Наш код... } - фигурные скобки обозначают блок кода, который будет выполняться при вызове функции main().

std::cout << "Hello, World!" << std::endl; - это вывод строки "Hello, World!" в стандартный вывод (обычно консоль). std::cout - это поток вывода, << - оператор вставки, и std::endl - конец строки с автоматической очисткой буфера.

return 0; - это оператор возврата, который сообщает операционной системе, что программа успешно завершилась. Возврат нуля обычно указывает на успешное выполнение программы.

Таким образом, при запуске этой программы на экране будет выведено "Hello, World!", и программа завершится с кодом возврата 0.


-----------------------------------

#include <iostream>
  
int main()
{
    std::cout << "Hello world!";
}

Комментарии:

Исходный код может содержать комментарии. Комментарии позволяют понять смысл программы, что делают те или иные ее части. При компиляции комментарии игнорируются и не оказывают никакого влияние на работу приложения и на его размер.

В языке C++ есть два типа комментариев: однострочный и многострочный. Однострочный комментарий размещается на одной строке после двойного слеша //:

#include <iostream>               // подключаем библиотеку iostream
  
int main()                          // определяем функцию main
{                                   // начало функции
    std::cout << "Hello World!";   // выводим строку на консоль
    return 0;                       // выходим из функции
}                                   // конец функции


#include <iostream>
/* В языке С++ существует понятие пространство имен.
 Это пространство определяет некую область,
 на которую приходятся действия оператора
 или функции. Для того, чтобы использовать оператор,
 находящийся в определенном пространстве, необходимо
 подключить это пространство в свою программу.
 Ниже подключается пространство под названием std

std:: в C++ представляет собой пространство имен (namespace) в стандартной библиотеке C++. Это сокращение от "standard" (стандарт). Пространство имен std содержит множество классов, функций и объектов, предоставляемых стандартной библиотекой языка C++.

Когда вы видите что-то вроде std::cout или std::cin, это означает, что объект (например, cout для вывода на консоль или cin для ввода с консоли) находится в пространстве имен std. Вот пример использования std::cout:

cout - это объект, предоставленный стандартной библиотекой для вывода на консоль. Пространство имен std обеспечивает организацию этих объектов и функций, чтобы избежать конфликтов имен с пользовательским кодом. Если пространство имен std не использовать явно, то для каждого элемента из стандартной библиотеки придется использовать ключевое слово std:: перед его именем.

Включение <iostream> в приведенном выше примере позволяет использовать объекты и функции из стандартной библиотеки ввода/вывода (iostream).

using namespace std; в C++ является директивой, которая сообщает компилятору, что вы хотите использовать все элементы (классы, функции и объекты) из пространства имен std без явного указания префикса std::.

Пространство имен std (от "standard") содержит стандартную библиотеку C++, включающую множество полезных классов и функций для работы с вводом, выводом, контейнерами, алгоритмами и многими другими аспектами программирования.

Вот пример использования using namespace std;:

#include <iostream>

using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}


В этом примере using namespace std; позволяет напрямую использовать cout и endl без префикса std::. Это делает код более компактным, но также может привести к потенциальным конфликтам имен, если ваш код содержит свои собственные имена, которые могут пересекаться с именами из пространства имен std. В больших проектах часто рекомендуется избегать использования using namespace std; и явно указывать префикс std:: для необходимых элементов.

Размеры и диапазоны значений типов данных в C++ могут зависеть от компилятора и архитектуры системы. Однако, обычно они следующие:

int: Обычно 4 байта. Диапазон: от -2,147,483,648 до 2,147,483,647.

unsigned int: Обычно 4 байта. Диапазон: от 0 до 4,294,967,295.
unsigned short: Обычно 2 байта. Диапазон: от 0 до 65,535.
unsigned long: Обычно 4 байта. Диапазон такой же, как и у unsigned int.
unsigned long long: Обычно 8 байт. Диапазон: от 0 до 18,446,744,073,709,551,615.

Числа с плавающей точкой:
float: Обычно 4 байта. Приблизительно 7 значащих цифр. Диапазон: от приблизительно ±1.17549e-38 до ±3.40282e+38.
double: Обычно 8 байт. Приблизительно 15 значащих цифр. Диапазон: от приблизительно ±2.22507e-308 до ±1.79769e+308.

Символьные типы:

wchar_t: Обычно 2 или 4 байта. Используется для широких символов, таких как Unicode.

Логический тип:
bool: Обычно 1 байт. Принимает значения true или false.

Строковый тип:
std::string: Размер может варьироваться в зависимости от реализации STL, но обычно управляется динамически.

Ключевые слова в C++ - это зарезервированные слова, которые имеют специальное значение для языка и не могут быть использованы в качестве идентификаторов. Например, int, float, if, while - это ключевые слова.

Константа — область оперативной памяти, обладающая
собственным именем и предназначенная для хранения
постоянных данных.

В C++, константы могут быть объявлены с использованием ключевого слова const.

#include <iostream>

int main() {
    const int MAX_VALUE = 100;
    const double PI = 3.14;
    const char GRADE = 'A';

    std::cout << "Max Value: " << MAX_VALUE << std::endl;
    std::cout << "PI: " << PI << std::endl;
    std::cout << "Grade: " << GRADE << std::endl;

    // Попытка изменить константу приведет к ошибке компиляции
    // MAX_VALUE = 200; // Ошибка!

    return 0;
}

Переменная представляет именнованный участок памяти. Переменная имеет тип, имя и значение. Тип определяет, какие именно данные может хранить переменная.

Синтаксис объявления переменных:
Объявление переменной в C++ включает в себя указание её типа и идентификатора. Синтаксис следующий:

тип_переменной идентификатор;

Примеры:

int age;
double salary;
char initial;

Инициализация переменной:
Инициализация переменной представляет собой присвоение начального значения в момент её объявления. Это может быть сделано несколькими способами.

Присвоение значения после объявления:
int count; // объявление переменной
count = 10; // присвоение значения

Именование переменных
Имя переменной последовательность алфавитных-цифровых символов и знака подчеркивания _. При этом имя переменной должно начинаться с алфавитного символа или подчеркивания.

Кроме того, в качестве имени переменной нельзя использовать ключевые слова языке C++, например, for или if. Но таких слов не так много, и по ходу освоения C++ вы соориентируетесь, какие слова являются ключевыми.


Также стоит учитывать, что C++ - регистрозависимый язык, а это значит, что регистр символов имеет большое значение. То есть в следующем коде будут определяться две разные переменные:

int age;
int Age;

Инициализация:

В C++ есть три вида инициализации:

Нотация присваивания (assignment notation)

Функциональная нотация (functional notation)

Инициализация в фигурных скобках (braced initialization)

Нотация присваивания:

Суть нотациия присваивания - с помощью оператора присваивания (знак "равно" или =) переменной передаем некоторое значение:

int age;
age = 20;

Инициализация в фигурных скобках:
При инициализации braced initialization после названия переменной в фигурных скобках указывается ее значение:

int age {38};   // braced initialization


Функциональная нотация:
При функциональной нотации после названия переменной в круглых скобках указывается ее значение:

int age (38);   // functional notation


Можно сразу инициализировать несколько переменных:
int age1 {22}, age2 (23), age3 = 24;

Операторы:

В программировании оператор - это символ или ключевое слово, которое выполняет определенное действие. Операторы используются для манипуляции данными, выполнения операций и управления потоком выполнения программы.

Примеры операторов в языке C++:

Арифметические операторы: +, -, *, /, %.
Логические операторы: &&, ||, !.
Операторы ветвлений: if, else, switch.
Унарные операторы: ++, --, !.
Бинарные операторы: +, -, *, /.
Тернарный оператор: ? :.
Операторы присваивания: =, +=, -=, и так далее.
	

Операнд:
Операнд - это объект, с которым оператор выполняет свою операцию. В выражении операторы могут действовать на один или несколько операндов.

Примеры операндов:

Числа: 5, 3.14, 1000.
Переменные: x, y, result.
Выражения: a + b, x * y, sum / count.
Пример выражения с операторами и операндами

int x = 5;      // Оператор присваивания (=), операнд: переменная x.
int y = 10;     // Оператор присваивания (=), операнд: переменная y.
int result = x + y;  // Арифметический оператор (+), операнды: переменные x и y.



Арифметические операторы:
Оператор сложения +:
int a = 5, b = 3;
int sum = a + b; // sum = 8

Оператор вычитания -:
int a = 5, b = 3;
int diff = a - b; // diff = 2

Оператор умножения *:
int a = 5, b = 3;
int product = a * b; // product = 15

Оператор деления /:
int a = 10, b = 2;
int quotient = a / b; // quotient = 5

Оператор остатка %:
int a = 10, b = 3;
int remainder = a % b; // remainder = 1

Логические операторы:
Логическое И &&:
bool p = true, q = false;
bool result = p && q; // result = false

Логическое ИЛИ ||:
bool p = true, q = false;
bool result = p || q; // result = true

Логическое НЕ !:
bool p = true;
bool result = !p; // result = false

Операторы ветвлений:
Оператор if (если):
int x = 10;
if (x > 5) {
    // Код, выполняющийся, если x > 5
}

Оператор else (иначе):
int x = 10;
if (x > 5) {
    // Код, выполняющийся, если x > 5
} else {
    // Код, выполняющийся, если x <= 5
}

Оператор switch (переключатель):
int day = 3;
switch (day) {
    case 1:
        // Код для понедельника
        break;
    case 2:
        // Код для вторника
        break;
    // Другие случаи...
    default:
        // Код для случая, если не совпал ни один из case
}


Унарные операторы:
Инкремент ++:
int x = 5;
x++; // Постфиксная форма: увеличение x на 1, x = 6
++x; // Префиксная форма: увеличение x на 1, x = 7

Декремент --:
int y = 10;
y--; // Постфиксная форма: уменьшение y на 1, y = 9
--y; // Префиксная форма: уменьшение y на 1, y = 8

Сокращенные формы операторов присваивания и арифметических операторов в C++:
Операторы присваивания:
Оператор += (сложение и присваивание):int x = 5;
x += 3; // Эквивалентно x = x + 3; // x становится равным 8

Оператор -= (вычитание и присваивание):
int y = 10;
y -= 4; // Эквивалентно y = y - 4; // y становится равным 6

Оператор *= (умножение и присваивание):
int z = 3;
z *= 2; // Эквивалентно z = z * 2; // z становится равным 6

Оператор /= (деление и присваивание):
int a = 8;
a /= 2; // Эквивалентно a = a / 2; // a становится равным 4


Тернарный оператор, также известный как условный оператор, представляет собой оператор с тремя операндами. Синтаксис тернарного оператора в C++ выглядит следующим образом:

condition ? expression_if_true : expression_if_false;

Он выполняет следующие шаги:

Вычисляет условие condition. Если condition истинно, то возвращается значение выражения expression_if_true.
Если condition ложно, то возвращается значение выражения expression_if_false.
Пример использования тернарного оператора:

#include <iostream>

int main() {
    int x = 10;
    int y = 5;

    // Используем тернарный оператор для выбора меньшего значения
    int min_value = (x < y) ? x : y;

    std::cout << "Min value: " << min_value << std::endl;

    return 0;
}


В данном примере, если x меньше y, то min_value примет значение x, иначе примет значение y. Это позволяет сделать выбор между двумя значениями на основе условия.

Тернарный оператор удобен для использования в коротких условных выражениях, где нужно выбрать значение в зависимости от условия.

Понятие enum:

Перечисление (enum) — это набор именованных целочисленных констант.

enum (перечисление) в C++ представляет собой пользовательский тип данных, который позволяет определить набор именованных констант (перечислителей), причем каждому из них автоматически присваивается уникальное целочисленное значение.


1. Простое объявление:

enum Color {
    Red,
    Green,
    Blue
};

В этом примере Color - это имя перечисления, а Red, Green, Blue - его перечислители. По умолчанию им присваиваются значения 0, 1, 2, и так далее.

Использование в переменных:
Color selectedColor = Red;


2. Явное присвоение значений:

enum Status {
    OK = 0,
    Error = 1,
    NotFound = 404
};


Пример:
#include<iostream>
using namespace std;

enum Day {
    Monday,   // 0
    Tuesday,   // 1
    Wednesday, // 2
    Thursday,  // 3
    Friday,    // 4
    Saturday,  // 5
    Sunday     // 6
};

int main() {
	
    Day a = Wednesday;
    cout << a;


	return 0;
}
