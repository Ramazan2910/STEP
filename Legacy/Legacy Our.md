# Использование унаследованного программного кода
- Почему необходимо использовать унаследованный программный код.
- Пространство System.Runtime.InteropServices.
- Взаимодействие с модулями Dll


## Почему необходимо использовать унаследованный программный код

`Унаследованный код` или `Legacy Code` - это код, который уже был 
написан и может быть не поддерживается. К примеру можем взять некоторые 
`.dll` файлы операционной системы Windows, которые были написаны. Все когда-то
видели messageBox или другие окна, которые выводятся на экран. Если данный 
инструмент уже написан, то почему бы его не использовать в нашей программе ? 

Для этого и существует пространство `System.Runtime.InteropServices`, которое
может импортировать нужный нам модуль и использовать его в нашем коде.

Также в придачу мы сегожня пройдем ключевое слово `extern`, которое позволяет
нам использовать функции из других модулей.

Пример программы будет в `Program.cs` файле.



```csharp 
using System;
using System.Runtime.InteropServices;
/*Пространство имен System.Runtime.InteropServices содержит типы, которые обеспечивают поддержку взаимодействия с кодом, написанным на неуправляемых языках программирования.*/

class Program
{
    // Загрузка DLL и вызов функции
    [DllImport("user32.dll", CharSet = CharSet.Auto)]
    public static extern int MessageBox(int hWnd, string text, string caption, uint type);

    static void Main()
    {
        MessageBox(0, "Hello from DLL!", "DLL Example", 0);
    }
}
```


`📌 DllImport:`
`DllImport` — это атрибут в C#, который используется для подключения внешних функций, находящихся в неуправляемых библиотеках (причем библиотека может быть написана на абсолютно другом языке), таких как DLL (Dynamic Link Libraries). С помощью этого атрибута мы указываем, что используем функцию из внешней библиотеки в коде C#.

`📂 "user32.dll":`
`user32.dll` — это стандартная динамическая библиотека Windows, которая содержит функции для работы с оконным интерфейсом пользователя (например, создание окон, кнопок, сообщений и т.п.).

Эта библиотека предоставляет множество функций, которые можно использовать для работы с окнами, клавишами, мышью и другими элементами интерфейса.

`extern` — этот модификатор говорит компилятору, что метод реализован вне текущей программы (в данном случае, в DLL). Мы не пишем код этого метода, а просто сообщаем, что его реализация находится в user32.dll.

`📌 int MessageBox(...):`
Это описание метода MessageBox, который будет вызван из user32.dll.

MessageBox — это функция, которая отображает модальное окно с сообщением для пользователя.

`📌 Параметры метода MessageBox:`
`int hWnd` — это идентификатор окна, с которым будет связано окно сообщения. В нашем случае это часто передаётся как 0, если окно не привязано к конкретному.

`string text` — текст, который будет отображаться в окне сообщения.

`string caption` — заголовок окна сообщения.

`uint type` — тип окна сообщения, который определяет, какие кнопки будут отображаться (например, OK, Cancel, Yes, No). Обычно это перечисление, например, MessageBoxButtons.OK или MessageBoxButtons.YesNo.
